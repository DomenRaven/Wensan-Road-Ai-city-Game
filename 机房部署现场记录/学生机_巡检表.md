## 学生机操作（按顺序）

### 一次性安装（每台 · 管理员 PowerShell）

> **推荐**：下方 **一键部署**（含 §8 自检 + 启动助手 v1.0.1）。  
> **前提**：服务器 `_tools\Godot\` 已发布（手册 §2.5）。

#### 一键部署 + 自检 + 启动助手

```powershell
# ========== 可按机房改这两行 ==========
$ServerIp = "10.71.121.18"
$NetUser  = "10.71.121.18\TEST1"   # 全班可共用同一 SMB 账号；按提示输入密码

$ErrorActionPreference = "Stop"
$ToolsUnc = "\\$ServerIp\GameForgeWorkspace\_tools"
$Helper   = "C:\GameForge\GameForgeLabHelper.exe"
$Godot    = "C:\Godot\Godot_v4.6.3-stable_win64.exe"

Write-Host "=== GameForge 学生机一键部署 ===" -ForegroundColor Cyan
Enable-NetFirewallRule -DisplayGroup "文件和打印机共享" -ErrorAction SilentlyContinue | Out-Null

New-Item -ItemType Directory -Force -Path "C:\GameForge" | Out-Null
Copy-Item "$ToolsUnc\GameForgeLabHelper.exe" $Helper -Force
Copy-Item "$ToolsUnc\launch-session-godot.ps1" "C:\GameForge\launch-session-godot.ps1" -Force
Write-Host "[1/4] 已从共享复制助手 v1.0.1" -ForegroundColor Green

& $Helper deploy --net-user $NetUser
if ($LASTEXITCODE -ne 0) { throw "deploy 失败，exit=$LASTEXITCODE" }
Write-Host "[2/4] deploy 完成" -ForegroundColor Green

$rows = @()
$rows += [pscustomobject]@{ Check = "Z: 映射"; Pass = (Test-Path "Z:\") }
$rows += [pscustomobject]@{ Check = "Godot exe"; Pass = (Test-Path $Godot) }
$rows += [pscustomobject]@{ Check = "lab_helper.json"; Pass = (Test-Path "C:\GameForge\lab_helper.json") }
$rows += [pscustomobject]@{ Check = "启动脚本"; Pass = (Test-Path "C:\GameForge\launch-session-godot.ps1") }
$rows += [pscustomobject]@{ Check = "助手 exe"; Pass = (Test-Path $Helper) }
try {
  $k = Invoke-WebRequest "http://${ServerIp}:8080/kiosk/edu/" -UseBasicParsing -TimeoutSec 8
  $rows += [pscustomobject]@{ Check = "Kiosk 8080"; Pass = ($k.StatusCode -eq 200) }
} catch { $rows += [pscustomobject]@{ Check = "Kiosk 8080"; Pass = $false } }
try {
  $a = Invoke-RestMethod "http://${ServerIp}:8000/health" -TimeoutSec 8
  $rows += [pscustomobject]@{ Check = "API local_share"; Pass = ($a.play_launch_mode -eq "local_share") }
} catch { $rows += [pscustomobject]@{ Check = "API local_share"; Pass = $false } }
$rows | Format-Table Check, Pass -AutoSize
if ($rows.Pass -contains $false) { throw "§8 自检未全过" }

Get-Process GameForgeLabHelper -ErrorAction SilentlyContinue | Stop-Process -Force -ErrorAction SilentlyContinue
Start-Process $Helper
Start-Sleep -Seconds 2
$h = Invoke-RestMethod http://127.0.0.1:17890/health -TimeoutSec 5
Write-Host "[4/4] 助手 health: ok=$($h.ok) version=$($h.version)" -ForegroundColor Green
if ($h.version -ne "1.0.1") { Write-Warning "期望 version=1.0.1" }
Write-Host "完成 → http://${ServerIp}:8080/kiosk/edu/" -ForegroundColor Cyan
```

## 常见问题（现场）

| 现象 | 处理 |
|------|------|
| `net use` 失败 | 学生机 `Enable-NetFirewallRule -DisplayGroup "文件和打印机共享"` |
| 网页开但 AI 不工作 | 服务器 `api_base` 是否为 LAN IP（已 OK） |
| Godot 找不到工程 | 检查 Z: 与 `project_path` 是否换成 `Z:\users\...` |
| `deploy` 报共享盘无 Godot | 服务器先执行 §2.5 发布 Godot 到 `_tools\Godot\` |
| 试玩不自动开 Godot | 确认 `GameForgeLabHelper.exe` 在跑 · `/health` ok |
| 关 Godot 不弹榜 | 须 Kiosk 三文件已同步 + 本会话**首轮**试玩（LB-2） |
| release 失败 | 先关 Godot |
