## 学生机操作（按顺序）

### 一次性安装（每台 · 管理员 PowerShell）

```powershell
New-Item -ItemType Directory -Force -Path "C:\GameForge" | Out-Null
Copy-Item "\\10.71.121.18\GameForgeWorkspace\_tools\GameForgeLabHelper.exe" `
  "C:\GameForge\GameForgeLabHelper.exe" -Force
Copy-Item "\\10.71.121.18\GameForgeWorkspace\_tools\launch-session-godot.ps1" `
  "C:\GameForge\launch-session-godot.ps1" -Force

C:\GameForge\GameForgeLabHelper.exe deploy --net-user "10.71.121.18\TEST1"
# 将 TEST1 换成该生服务器账号；按提示输入密码

Test-Path "C:\Godot\Godot_v4.6.3-stable_win64.exe"
Test-Path "C:\GameForge\lab_helper.json"
```

> **前提**：服务器 `_tools\Godot\` 已发布（手册 §2.5）。若 `deploy` 报「共享盘无 Godot」，先在服务器执行命令块 D。

### 每课时上课前（学生或教师）

1. 双击 **`C:\GameForge\GameForgeLabHelper.exe`**（黑窗口保持开着，勿关）
2. 或管理员 PowerShell：

```powershell
Start-Process "C:\GameForge\GameForgeLabHelper.exe"
Start-Sleep -Seconds 2
Invoke-RestMethod http://127.0.0.1:17890/health
```

期望输出含 `ok : True`。

### 上课时（学生浏览器）

1. 打开 http://10.71.121.18:8080/kiosk/edu/
2. 登录 → 选品类 → 制作完成 → **开始试玩**
3. Godot **自动弹出**（无需手输路径）
4. 玩完 **关 Godot** → 网页 **首轮**自动弹今日榜单
5. 再试玩 / AI 改后关 Godot → **不再**自动弹榜（LB-2）
6. 下课点 **回主页 release**

## 常见问题（现场）

| 现象 | 处理 |
|------|------|
| `net use` 失败 | 学生机 `Enable-NetFirewallRule -DisplayGroup "文件和打印机共享"` |
| 网页开但 AI 不工作 | 服务器 `api_base` 是否为 LAN IP（已 OK） |
| Godot 找不到工程 | 检查 Z: 与 `project_path` 是否换成 `Z:\users\...` |
| `deploy` 报共享盘无 Godot | 服务器先执行 §2.5 发布 Godot 到 `_tools\Godot\` |
| 试玩不自动开 Godot | 确认 `GameForgeLabHelper.exe` 在跑 · `/health` ok |
| 关 Godot 不弹榜 | 须 Kiosk 三文件已同步 + 本会话**首轮**试玩（LB-2） |
| release 失败 | 先关 Godot |
