## 故障与热修（工作足迹）

### 现象

- 浏览器试玩页：`本机试玩就绪 · 助手将自动打开 Godot`（**非**「本机 Godot 已启动」）
- 助手 `/launch` 返回：`找不到 project.godot: Z:fb5264fd-...`（**Z: 后无 `\`**）
- 手动 `launch-session-godot.ps1` 同路径 **可** 启动 Godot

### 根因

Python `Path("Z:") / "session_id"` 在 Windows 上生成 `Z:session_id`，不是共享根 `Z:\session_id`；PowerShell `Join-Path` 行为正确。

### 修复

- 文件：`05-工具脚本/lab_godot_helper.py`
- 新增 `local_drive_root()` · 版本 **1.0.1**
- 开发机 `build_lab_helper.ps1` → 发布 `_tools` → 学生机覆盖 `C:\GameForge\GameForgeLabHelper.exe`

### 验收命令（学生机）

```powershell
Invoke-RestMethod http://127.0.0.1:17890/health   # version=1.0.1
$body = @{ project_path = "<SessionPath>"; force = $true } | ConvertTo-Json
Invoke-RestMethod http://127.0.0.1:17890/launch -Method POST -ContentType "application/json" -Body $body
# local_path 须为 Z:\xxx（带反斜杠）
```
