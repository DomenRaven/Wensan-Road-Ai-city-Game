## 1. 诊断结论（同类模式）

| ID | 位置 | 风险 | 处置 |
|----|------|------|------|
| **V-1** | `session.js` `apiWithSession` | 任意 `404` → 重建会话 → login takeover 删盘 | ✅ 仅 `Session not found` |
| **V-2** | `edu-wizard.js` generate 重试 | 任意 `404` 触发 `ensureBuildSession` | ✅ 复用 `isSessionMissingError` |
| **V-3** | `ensureSession` 探活 | 非 404/403 语义不清时可能误重建 | ✅ 404 且正文含 Session not found 才重建；403 原样抛出 |
| **V-4** | `releaseBeacon` + `pagehide` | AI/制作中切后台误清盘 | ✅ `protectRelease` 时跳过 beacon；nl-patch 期间置位 |
| **V-5** | `GET /bootstrap` | 每次清孤儿 → memory 空会话全删 | ✅ 已只读缓存；memory 冷启动跳过 |
| **V-6** | 榜单轮询 `nlOpen` | DOM 存在即当打开 → 永不弹榜 | ✅ `!hidden` + 关弹层补弹 |
| **V-7** | Diff `session_id` 严等 | 重建后 turn 404 | ✅ 登录本人跨 sid 可读 |
| **OK** | A 链 `kiosk/wizard.js` | 无「404 误重建」模式 | 无需改 |
| **OK** | login 单会话 takeover | **有意**删旧盘 | 保留；前端禁止误触发即可 |
