## 1. 总览（教学增量）

| 层 | 路径模式 | 读写 | 职责 |
|----|----------|------|------|
| 认证 | `backend/app/routers/auth.py`（新建）· `services/auth_*.py`（新建） | 可写 | 注册/登录/登出/`me`；密码哈希 |
| 用户存储 | `data/learning_analytics/` 内用户表或等价 | 可写 | 与学情同库优先（少依赖） |
| 会话归属 | `backend/app/models/session.py` · `stores/session_store.py` · `routers/sessions.py` | 可写 | `user_id`/`guest`；单活跃会话 |
| 工作区根 | `backend/app/services/workspace_guard.py` | 可写 | 登录路径 `users/{user_id}/{session_id}`；游客扁平 UUID |
| 学情服务 | `backend/app/services/learning_analytics*.py`（新建） | 可写 | SQLite CRUD；release 不删 |
| 学情库文件 | `data/learning_analytics/learning.db` · `blobs/` | 服务写 | **禁止**写入 `data/learned_skills/` |
| nl-patch | `routers/nl_patch.py` · `services/creative/llm_patch.py` · `game_agent.py` | 可写 | 回合落库；评价注入；S4 排队入口 |
| Diff | `services/creative/` 或 `services/turn_diff*.py`（新建） | 可写 | before 快照、unified diff |
| 工作区读 | `routers/sessions.py`（`workspace/file` 白名单） | 可写 | 扩 `scenes/`；新增 `workspace/tree` |
| 试玩模式 | `routers/play.py` · `config.py` · `godot_launcher.py` | 可写 | `server` vs `local_share`；后者不起服务器 Godot |
| Kiosk 入口 | `kiosk/edu/` 新初始页 · `index` 路由 | 可写 | 游客∥登录 |
| 命名/向导 | `kiosk/edu/edu-wizard.js` · B2 相关 | 可写 | 登录跳过创作者名；F4-N3 默认名 |
| 证书门闩 | `kiosk/edu/certificate.js` · `edu-wizard.js` | 可写 | 保存成功 → 解锁 F1 按钮 |
| 代码浏览 | `kiosk/edu/code-browser*.js`（新建）· CSS | 可写 | 树+阅读区；勿冒充剧场 |
| Diff/评价 UI | `kiosk/edu/nl-patch-dialog.js` | 可写 | 看 Diff、打星 |
| 注解表 | `config/code_annotations/{genre}.json`（新建，可简） | 可写 | F1 文件级说明 |
| 品类中文名 | `config/kiosk_edu_spec.json` → `genre_display_names` | **只读引用** | 命名用；勿臆造「射击战士」 |
| 玩法冻结 | `templates/{genre}/core/**` | **只读** | 禁止改 |
| Edu 桥/触控 | `templates/_edu/**` | 可写（非必须本包） | 仅当教学能力依赖桥时 |
| Learned Skill | `data/learned_skills/**` | 勿混用 | 仍守 G8；非学情库 |
| 单测 | `backend/tests/test_auth_*` · `test_learning_*` · `test_turn_*` · `test_workspace_tree_*` | 可写 | P0 覆盖 |
| 配置 | `backend/app/config.py` · `.env.example` | 可写 | `max_sessions`、`max_concurrent_agents`、`play_launch_mode` |

## 2. 按工作包映射（施工顺序）

| 包 | 主要触点 |
|----|----------|
| W1 入口账号 | `kiosk/edu/*` 初始页；`auth` 路由；`session` 绑定；`workspace_guard`；`edu-wizard` B2 |
| W2 学情 | `learning_analytics*`；`llm_patch`/`nl_patch` 结束钩子；`sessions.release` 不删库 |
| W3 评价 | `nl-patch-dialog.js`；rating API；`llm_patch` 注入上下文 |
| W4 Diff | 快照服务；nl-patch 前后钩子；对话框 Diff UI；blobs |
| W5 F1 | `workspace/tree`+file 白名单；code-browser 页；certificate 成功标志；注解 JSON |
| W6 S4 | `llm_patch` 或独立 queue；`config.max_concurrent_agents`；前端排队文案 |
| W7 S2 钩子 | `play.py` + `config.play_launch_mode`；local_share 响应契约 |

## 3. API 增量清单（示意路径，实现可微调）

| 方法 | 路径（示意） | 包 |
|------|--------------|----|
| POST | `/auth/register` `/auth/login` `/auth/logout` | W1 |
| GET | `/auth/me` | W1 |
| GET | `/sessions/{id}/workspace/tree` | W5 |
| GET | `/sessions/{id}/workspace/file`（扩白名单） | W5 |
| GET | `/sessions/{id}/turns/{turn_id}/diff` | W4 |
| POST | `/sessions/{id}/turns/{turn_id}/rating` | W3 |
| GET | `/admin/analytics/...`（可 P1） | P1 |
| POST | `/sessions/{id}/play/launch`（行为分模式） | W7 |

鉴权：资源 `user_id` 与 Token 不一致 → **403**。

- `templates/platformer|shmup|survivor|pingpong|fighting|parkour|racing/core/**`

- 在无 `local_share` 配置时删除现网服务器 `play/launch` 行为（展厅默认须保持）
