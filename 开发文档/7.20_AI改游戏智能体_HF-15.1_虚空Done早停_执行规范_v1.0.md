## 1. 实现要点

### 1.1 非法 evidence（`agent_contracts`）

在 `normalize_evidence_list` 之后或 `_assert_one_evidence_wired` 入口：

- 若 `path` 以 `.tscn`/`.tres` 结尾 → error：`evidence 不可用场景路径当 symbol：请改为 .gd 中的 func/var…`  
- 若 `wired_by` 匹配 `->` 或含 `.gd->_` 散文 → error：`wired_by 须为函数名或 A|B，禁止箭头链`  

### 1.2 Evidence ⊆ 本轮（策略拍板）

当 `require_evidence` 且 `written_paths` 非空：

- 对每条 evidence：在 `workspace_root/path` 上 `_find_symbol_kind` 必须非空（已有）。  
- **额外**：若符号在**回合初 snapshot** 的该文件中不存在，则本轮 `written_paths` 必须包含该 `path`（新符号须来自本轮写入）。  
- 若符号回合初已存在，允许 path 不在 written（只改接线方）——避免误杀「只改 `_physics_process` 调用」。

回合初 snapshot：`game_agent` 已有 pre-turn 文件字节；传入 assert 或在 agent 侧预检。

### 1.3 同错早停（`game_agent` 主循环）

- 每次 `self_check`/`done` 门禁失败，抽取 errors 归一化键集合（建议：去掉中文标点后的稳定前缀，或 `symbol_undefined:{symbol}@{path}` / `wired_by_format` / `l2_*`）。  
- 若与上一失败键集合的 Jaccard ≥ 0.8（或完全相等）则 `streak++`，否则 `streak=1`。  
- `streak >= 3`：打破工具循环，走 `_salvage` / partial 返回，message 含「连续三次相同门禁失败，已停止空转」+ 缺口列表。  
- 与 HF-13「同错换路」协调：早停优先于继续换路烧轮。

### 1.4 `symbols_added`

`replace_text` 成功后，对 `new_text` 用正则 `(?m)^\s*func\s+(\w+)` 提取，observation 增加 `symbols_added: list[str]`（上限 20）。

### 1.5 done / self_check

可选硬规则：若本轮最近一次 `self_check` 返回 `ok=false`，紧接着的 `done` 不进入成功收尾，直接回灌 self_check.errors（避免跳过自检）。
