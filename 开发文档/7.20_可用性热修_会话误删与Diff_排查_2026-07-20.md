# 7.20 · 会话误删 / Diff 404 / 工作区空白 · 排查与修复

> **日期**：2026-07-20  
> **现象**：临时工作区无法加载；AI 改游戏 Diff「turn not found」；对话历史像丢失；试玩/全屏失败  

---

## 根因链

1. **Redis 未运行** → `session_backend=memory`（`ALLOW_MEMORY_FALLBACK=true`）。  
2. **API 重启或冷启动** → 内存会话清空，`active_session_ids` 为空。  
3. **`GET /bootstrap` 每次调用 `run_startup_bootstrap` 并执行 `cleanup_orphan_workspaces`** → 把磁盘上全部 `workspace/`（含 `users/{uid}/{sid}/`）当孤儿删除。  
4. 前端仍持有旧 `session_id` / `turn_id` / `lastResult` → 探活 404 后**静默建新会话**（空工作区）→ tree `404 workspace 尚未生成`；Diff 用新 sid + 旧 turn → `404 turn not found`。  
5. 无 `project.godot` → 试玩启动失败，全屏贴窗无从谈起。

## 修复口径

| ID | 措施 |
|----|------|
| **SW-1** | `GET /bootstrap` **只读缓存报告**，不再每次清盘；清理仅 startup / `POST /bootstrap/refresh` |
| **SW-2** | memory 冷启动且无活跃会话：**跳过**孤儿全量清理；其余清理加 **最短存活时间**（防刚写完被误删） |
| **SW-3** | Diff/评价：登录用户可用**新 session 路径**读取**本人**旧 `turn_id`（放宽 sid 全等） |
| **SW-4** | 前端：会话被重建时清空 nl-patch `lastResult`/history、向导 `workspacePath`；代码浏览加载失败清空右侧残留 |
| **SW-5** | 运维：尽量拉起 Redis，使 `session_backend=redis` |

## 手测

1. `health.session_backend` 优先为 `redis`。  
2. 制作 → AI 改一轮 → 查看 Diff / 改后全文 / 工作区树均 OK。  
3. **重启 uvicorn（Redis 在跑）** → 同会话仍可试玩与看代码。  
4. 故意停 Redis、memory 冷启动 → **不得**清空已有 `workspace/users/...`。
