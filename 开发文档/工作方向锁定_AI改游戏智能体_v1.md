## 3. 原则（防「测一次改一次」）

1. **产品真 bug**（如桥每帧重建按钮）修在 `_edu` / 通用工具，不堆 intent if。  
2. **用户反馈**交给 Agent：`diagnose_workspace` + 读盘 + Skill，禁止复读 enable 冒充修复。  
3. **硬门禁**保留（声称⊆磁盘、无幻想 API）；**路由/catalog 是建议与捷径，不是能力天花板**。  
4. **默认尽量实现**：前所未有需求用会话 `core/scenes` 现场写；禁止用无关玩法冒充。  
5. 经验进 `data/learned_skills/`，跨局复用。

- **有 API Key**：只跑会话智能体；失败诚实回报，**禁止**降级旧「只改 tuning」的 LLM/stub。
