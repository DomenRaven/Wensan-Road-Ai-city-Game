## 3. 原则（防「测一次改一次」）

1. **产品真 bug**修在 `_edu` / 通用工具，不堆 intent if。  
2. **用户反馈**交给 Agent：读盘 + Skill 参考，禁止复读 enable 冒充修复。  
3. **硬门禁**保留；catalog / Learned / Reference = 材料，不是入口、不是天花板。  
4. **默认现场实现**带条件需求；禁止裸 enable 冒充。  
5. **整句优先**（秒哒 R3–R5）。  
6. **有效才入库**：终局仍「没生效/未实装」→ 不准有效 Learned Skill（总纲 G8）。  
7. **开放读盘 · 最大化 LLM（G11 / HF-11）**：需求与反馈同一多工具循环；本局改动清单注入；提示软、门禁硬；禁止场景补丁堆叠。
