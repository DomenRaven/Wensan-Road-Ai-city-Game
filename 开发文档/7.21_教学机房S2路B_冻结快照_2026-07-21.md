## 4. 已知硬限制（写入冻结，勿当回归 bug）

| 限制 | 说明 |
|------|------|
| **Win11 Pro SMB ~20 连接** | 同时 persistent `Z:` 映射约 ≤20 台 · 错误 71 = 满员 |
| **两套账号** | SMB Windows 用户 ≠ GameForge 网页登录 |
| **127.0.0.1 启服** | 学生机无法访问 · 须 `0.0.0.0` / `GameForgeLabServer --server-ip` |
| **UNC 直拷** | 须先 `net use Z:` |
