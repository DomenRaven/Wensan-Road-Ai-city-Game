## 2. 产品原则

| 交给 LLM | 不交给 LLM 单独裁定 |
|----------|---------------------|
| 怎么实现、读哪些文件、怎么 patch | 「我觉得图标已经显示」 |
| 在 evidence 里指出符号与调用点 | 用散文替代可解析证据 |
| summary / how_to_play 自然语言 | 自填 evidence 骗过门禁后当成功交付 |

机器层：

- **L0**：既有结构保真 / GDScript / dry_run（HF-12）  
- **L1**：`evidence[]` 定义 + 接线（HF-14，本窗修误杀）  
- **L2**：表现谓词（场景节点 + 属性写入/可见性）——**本窗 P0**  
- **Observe**：场景探针结果回灌（P1）

## 3. 功能需求

### R1 · L1 接线预言机加固（P0）

1. `wired_by` 支持多调用方（列表或 `A|B`）；任一条命中即可。  
2. 间接调用：允许 1～2 跳（如 `hit_by_enemy_body` → `take_hit` → `update_*`）。  
3. `symbol` 必须是单个标识符；复合串 → gate_error + 格式回灌。  
4. 注释/空白-only diff 不得满足接线或反馈真差分（延续 S3）。

### R2 · L2 表现预言机（P0）

当用户 goals / 原话命中高置信关键词时，机器追加谓词（**品类通用**，认 Godot UI/脚本结构）：

| 触发（示例） | 谓词族（须至少满足一族） |
|--------------|--------------------------|
| 进度条 / 冷却条 / 充能条 | 场景存在 `ProgressBar` 或 `TextureProgressBar`；且脚本对 `.value` / `.ratio` 等有写入，写入点在 `_process` / `_physics_process` / Timer 路径 |
| 图标 / 命数图标 / 血量图标显示 | 对应 `TextureRect`（或约定 Control）存在；且 `texture` 非空 **或** 代码路径提供可见占位（非零 `custom_minimum_size` + 非透明 modulate / 等价） |

未命中关键词 → 不跑 L2（避免误杀）。  
禁止写成 shmup/Boss 专用 if。

### R3 · 失败回灌（P0/P1）

`gate_errors` 须含**失败谓词原文**（含路径/节点名）；反馈轮注入该原文 +（P1）inspect 片段；禁止只注入上轮 summary。

### R4 · Observe 工具（P1）

只读 `inspect_scene_ui`（或 replace 后自动附带）：节点类型、texture、visible、min_size。  
供 LLM Observation，不替代 L2 硬核。

### R5 · Sprint 契约（P1，可选增强）

规则从原话抽取 `accept[]`；「没生效」时契约冻结，只补失败项。  
独立 LLM 最多审「契约是否覆盖原话」，**不得**当代码过关 Judge。

### R6 · 轨迹早停 / 运行探针（P2）

连续无净写入或 validate 死循环 → partial；可选短时桥状态探针。非本窗必达。

## 5. 验收（产品侧）

1. 合成：空 `TextureRect` 仅切 visible → **不能** `gate_passed`（当 goals 含图标显示）。  
2. 合成：ProgressBar 无 `.value` 写入 → **不能**过（当 goals 含进度条）。  
3. 合成：`take_hit` 调 `update_*`、evidence 写间接 caller → **能**过 L1。  
4. 合成：复合 `wired_by` 字符串 → 拒收并回灌，不误杀已接线代码（修好声明后可过）。  
5. HF-14 既有半成品无敌案仍不过门；HF-12 语义不回退。  
6. 文档与一致性校验对齐磁盘。
