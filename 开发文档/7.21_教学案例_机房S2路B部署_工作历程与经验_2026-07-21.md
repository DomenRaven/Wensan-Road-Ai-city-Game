## 0. 一句话故事

今天不是在「把展厅单机 demo 搬到机房」，而是把 **学生本机 Godot + 服务器 API/Kiosk + SMB 共享 workspace** 串成可上课的闭环，并在首台 §9 通过后，把踩坑写成 **可批量复制的一键部署 v2**。

**可对外讲的金句**：

> 浏览器只负责创作与 AI；**Z: 与 Godot 是 Windows 文件共享 + 本机助手**，和网页登录是两套账号。

**必须同时承认的事实**：

> 首台能过、第二台报错，往往不是「服务器又坏了」，而是 **脚本顺序 / Windows 路径语义 / SMB 未登录** 三类低级坑。

## 4. 故障实录 · 根因 · 热修（工作足迹）

### 4.1 试玩页「本机试玩就绪」但 Godot 不弹

| 项 | 内容 |
|----|------|
| **现象** | API `/play/launch` 成功；UI 显示「助手将自动打开 Godot」；非「本机 Godot 已启动」 |
| **诊断** | `POST http://127.0.0.1:17890/launch` → `找不到 project.godot: Z:fb5264fd-...`（**无 `\`**） |
| **对照** | 手动 `launch-session-godot.ps1` 同路径 **能** 开 Godot |
| **根因** | Python `Path("Z:") / sid` → `Z:sid`；PowerShell `Join-Path "Z:" $rel` → `Z:\sid` |
| **修复** | `lab_godot_helper.py` · `local_drive_root()` · **v1.0.1** |
| **经验** | **声称试玩成功须看助手 `/launch` 的 `local_path` 是否含 `Z:\`** |

### 4.2 新学生机 `Copy-Item \\10.71.121.18\...` 找不到路径

| 项 | 内容 |
|----|------|
| **根因** | SMB **未登录** 时 UNC 直拷失败（假「路径不存在」） |
| **修复** | **先 `net use Z:`**，再从 **`Z:\_tools\`** 复制 |
| **经验** | 首台能过 ≠ 脚本对；首台可能已有 Z: 映射 |

### 4.3 `net use Z: /delete` →「找不到网络连接」脚本中断

| 项 | 内容 |
|----|------|
| **根因** | 新机器本无 Z:；delete 写 stderr + `$ErrorActionPreference = Stop` → **误中断** |
| **修复** | `cmd /c "net use Z: /delete /y >nul 2>&1"` 静默忽略 |
| **经验** | **delete 失败在新机上是常态**，不是网络坏了 |

## 5. 双账号模型（最易混 · 必讲）

| | **Windows SMB 用户**（文档示例 `TEST1`） | **GameForge 浏览器用户** |
|--|------------------------------------------|---------------------------|
| **用途** | `net use Z:` · 读共享 workspace / `_tools` | Kiosk 注册登录 · session · AI 改游戏 |
| **存在位置** | 服务器 **Windows 本地用户** | `learning.db` |
| **全班共用？** | **可以** 一个 SMB 账号映射全班 Z: | 每人各自（或教师规定） |
| **脚本里写什么** | `$NetUser = "10.71.121.18\<真实Windows用户名>"` | 无需写进 deploy 脚本 |

**TEST1** = 文档占位示例名；首台 §9 用过的工作账号是什么，批量时就填什么。

查服务器用户（RDP）：

```powershell
Get-LocalUser | Where-Object Enabled -eq $true | Select-Object Name
```

## 7. 技能与经验（可复用）

### 7.1 部署原则

1. **服务器与学生机分开验**：服务器 §7 绿 ≠ 学生机 §9 绿。  
2. **声称 PASS 须有证据**：`Test-Path` · `/health` · `/launch` 的 `local_path` · 浏览器实测。  
3. **local_share 链路三段**：API 只回路径 → 助手 `:17890/launch` → 本机 Godot 读 **Z:\**。  
4. **批量脚本顺序 > 功能**：新机 SMB 未登录、Python `Path("Z:")`、PowerShell Stop 误中断，都出在**顺序与平台语义**。  
5. **两套账号分开讲**：避免学生/教师把 TEST1 当成网页密码。

### 7.2 诊断决策树（学生机试玩不开）

```text
浏览器「试玩就绪」但无 Godot
  ├─ /health 失败 → 助手未运行
  ├─ /launch local_path 为 Z:xxx（无 \）→ 助手版本 < 1.0.1
  ├─ /launch 找不到 project.godot → Z: 未映射或 session 已 release
  ├─ 手动 ps1 能开、浏览器不能 → 查 F12 / 助手是否 launch 失败（UI 不报错）
  └─ 全部 OK 仍不弹 → Godot 进程/显卡（少见）
```

### 7.3 课前 5 分钟 T6（服务器）

```powershell
Get-NetTCPConnection -LocalPort 8000,8080,445 -State Listen -ErrorAction SilentlyContinue |
  Select-Object LocalAddress, LocalPort
Invoke-RestMethod http://127.0.0.1:8000/health | Select-Object status, play_launch_mode, store_ok
```

全班：**每台助手黑窗口在跑** · `version=1.0.1`。

### 7.4 已知非阻塞（勿当部署失败）

Godot 控制台 `flushing queries` · `ai_sandbox_bridge` 信号参数 — **§9 已通过**，属 _edu 桥接/runtime，非机房阻塞。

### 7.5 与 Agent 主线的边界

| 机房轨 | Agent 轨 |
