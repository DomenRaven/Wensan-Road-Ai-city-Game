## 硬限制（Win11 专业版 SMB）

- 本机作 SMB 服务器时，**同时 persistent 映射 Z: 的学生机约 ≤20 台**（系统错误 71 = 连接满）。  
- 课前用 `Get-SmbSession | Measure-Object` 监控；满员时勿声称「全班 deploy 全过」。  
- 25 人课可接受 **≤20 台** 同时 Z: + 本机试玩；文档化实际可用台数。

## 第 0 步 · 目录 + 探测 LAN IP

```powershell
$ROOT = "E:\project\GameForge-K12"
Set-Location $ROOT
Get-ChildItem $ROOT -Name | Select-Object -First 20

# 探测教室 LAN IPv4（排除 127.* · 169.254.*）
$ServerIp = (
  Get-NetIPAddress -AddressFamily IPv4 -ErrorAction SilentlyContinue |
  Where-Object {
    $_.IPAddress -notmatch '^(127\.|169\.254\.)' -and
    $_.PrefixOrigin -ne 'WellKnown'
  } |
  Sort-Object InterfaceMetric |
  Select-Object -First 1 -ExpandProperty IPAddress
)
if (-not $ServerIp) { throw "无法探测 LAN IP · 请 ipconfig 人工指定" }
Write-Host "ServerIp=$ServerIp"
$ShareName = "GameForgeWorkspace"
$WorkspacePath = Join-Path $ROOT "workspace"
```

**必须存在：** `backend/` · `kiosk/` · `templates/` · `config/` · `05-工具脚本/` · `VERSION`

## 第 4 步 · workspace SMB 共享（§2）

```powershell
New-Item -ItemType Directory -Force -Path $WorkspacePath, "$WorkspacePath\_tools", "$WorkspacePath\_tools\Godot" | Out-Null
if (-not (Get-SmbShare -Name $ShareName -ErrorAction SilentlyContinue)) {
  New-SmbShare -Name $ShareName -Path $WorkspacePath -FullAccess "Everyone" -ChangeAccess "Everyone"

Test-Path "\\$ServerIp\$ShareName\_tools"
```

## 第 5 步 · 发布 `_tools` 三件套（§2.5 + §2.6）

```powershell
$Tools = "$WorkspacePath\_tools"
$HelperDest = Join-Path $Tools "GameForgeLabHelper.exe"
$LaunchDest = Join-Path $Tools "launch-session-godot.ps1"
$GodotDest  = Join-Path $Tools "Godot\Godot_v4.6.3-stable_win64.exe"

# 助手：优先 dist；无则 build
$HelperSrc = "$ROOT\05-工具脚本\dist\GameForgeLabHelper.exe"
if (-not (Test-Path $HelperSrc)) {
  Set-Location "$ROOT\05-工具脚本"
  powershell -ExecutionPolicy Bypass -File .\build_lab_helper.ps1
  $HelperSrc = "$ROOT\05-工具脚本\dist\GameForgeLabHelper.exe"
}
Copy-Item $HelperSrc $HelperDest -Force
Copy-Item "$ROOT\05-工具脚本\launch-session-godot.ps1" $LaunchDest -Force

# Godot：从 GODOT_PATH 或 C:\Godot 复制到 _tools\Godot\
Copy-Item $GodotPath $GodotDest -Force

Test-Path $HelperDest, $LaunchDest, $GodotDest
Invoke-RestMethod http://127.0.0.1:17890/health -ErrorAction SilentlyContinue
# 助手 version 须 1.0.1+
```
