## 0. 本阶段施工目标

在总纲 G1–G12 下，对话路径为：

> 有 Key → **第 1 轮起 LLM 多工具全开** → 整句 goals → **读盘优先** → 会话自由创作 → 门禁 → 手动重开  

Catalog / Learned / Reference = **材料**，不是入口。禁止 catalog express。

验收口诀：

**听全句 · 拆 goals · 读盘优先 · 写会话 · 条件落地 · 禁 express · 故障禁再 enable · 有效才 harvest · 七品类一致**

### 0.1 工程参数（总纲已拍板）

| 参数 | 锁定值 | 配置 / 环境变量 |
|------|--------|-----------------|
| `max_rounds` | **16** | `Settings.agent_max_rounds` / `AGENT_MAX_ROUNDS` |
| 软续杯 | 有进展再 **+16**（硬顶 32） | `agent_soft_extra_rounds` / `AGENT_SOFT_EXTRA_ROUNDS` |
| **墙钟** | **360s**（真实经过时间；与轮次无关） | `agent_wall_clock_sec` / `AGENT_WALL_CLOCK_SEC` |
| harvest | 终局否定态 **不准**有效 Learned Skill | `learned_skills.harvest_session_experience` |
| Reference | `data/reference_skills/` 启动摘要 + `read_reference_skill` | `reference_skills_dir` |

**墙钟**：从本次用户请求起算的墙上时间；满 360s 即使轮次未用完也诚实 partial 停。与 `max_rounds` 谁先碰到谁停。

## 1. 红线（继承 + 总纲追加）

### 1.1 继承

1. 禁止改 `templates/{genre}/core/**`。  
2. 允许改 `templates/_edu/**`、`config/agent_contracts/**`、`backend/.../creative/**`、`kiosk/edu`、`data/reference_skills/`。  
3. Agent 运行时只写 `workspace/{session}/`。  
4. 禁止幻想 API、禁止口头 done、禁止自动重开掩盖未落地。  

### 1.2 本阶段追加

5. **禁止**恢复有 Key 的 catalog express。  
6. **禁止**口语命中就强制 `enable_catalog_skill`（有附加条件必须写会话逻辑）。  
7. **禁止** bugfix /「没生效」仅 enable 交差。  
8. **禁止**终局否定态 harvest 为 `safety=ok` 有效 Skill。  
9. 不删 optional_skills / 契约 catalog 列表（降为参考）。  
10. shmup **掉落物专用实现能力保留**（真写 powerup）；HF-12 改为首轮 LLM 可调用工具，不保留 pre-LLM return。

## 4. 意图路由语义（总纲口径）

| 码 | 语义 |
|----|------|
| A | 命中 catalog → **建议参考** skill_ids；实现由 Agent 选（现场写优先于裸 enable） |
| B | 故障/调参修盘；硬禁 enable 交差 |
| C | 新机制自由创作（含「像 catalog 但带条件」）— 有 Key 时与 A 一样进多工具循环 |
| D | 幻想 API → 转会话 GDScript 实现，不硬劝退 |

有 Key：**第 1 轮起全开工具**；无「固定工作流失败后再开全工具」两阶段。

## 7. Live / 手工验收（当前暂停签字）

前置自动门槛已通过；本节为当前下一步。  

1. 有 Key；乒乓新局。  
2. 「我想要有大力扣杀」→ 理解/goals，**不是** rounds=0 秒开。  
3. 「每接 3 个球用一次，速度很快，对面反应不过来」→ goals≥3；磁盘有机制改动 ≠ 仅 enabled_skills。  
4. 「没生效」→ 不得再只回「已开启大力扣杀」；回主页后该局 **不应** 成为有效 Learned Skill（若终局仍否定）。  
5. 墙钟：长请求可观察进度；满约 6 分钟应 partial 诚实停（勿无限挂）。  
6. 抽测 shmup「发射激光」：进 Agent；掉落句由首轮 LLM 决定调用掉落专用工具。  
7. 每案保存目标 diff；不得删除非目标函数/信号/关键玩法链。
