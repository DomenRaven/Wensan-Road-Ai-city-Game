## 三、数据与 API

```text
存储：backend/data/leaderboard_daily/{genre}/{YYYY-MM-DD}.json
时区：Asia/Shanghai（backend/requirements.txt 含 tzdata · Windows 兼容）
POST  /leaderboard/{genre}/entries
GET   /leaderboard/{genre}/daily?date=today&limit=10
```

**run_complete 读取**：关窗后 `GET /sessions/{id}/play/actions` 取末条 `action_id=run_complete`（乒乓球须含 `session_end`）。
