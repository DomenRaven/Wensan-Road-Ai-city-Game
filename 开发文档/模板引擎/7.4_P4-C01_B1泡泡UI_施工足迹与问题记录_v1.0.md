## 三、修复方案摘要

### P03 · 格斗图标错位

```javascript
// b1-intent.js · CHIP_TEXT_GENRE 优先于 KEYWORD_MAP
"格斗双人": "fighting"  // → emoji 🥊
```

**经验**：快捷 chip 文案必须 **精确表映射**；`KEYWORD_MAP` 子串匹配顺序不可单独依赖。

### P04/P08/P09/P10 · 触控软键盘（真实 IME）

| 层 | 行为 |
|----|------|
| 前端 | `pointerdown` 同步 `focus` · `POST /kiosk/touch-keyboard/show` |
| 后端 | `show_touch_keyboard.ps1` → 切 zh-CN · TabTip ShowIfHidden · 检测搜狗 |
| 禁止 | 页面内自建假键盘 |

**运维必做**：默认输入法 = 搜狗拼音；键入 → 没有键盘时显示触摸键盘 = 开；8080 + 8000 双服务。

### P11 · 搜狗软键盘

**结论：不能独立 API 调用。** 推荐 TabTip + 搜狗作默认 IME。备选 `kiosk_edu_spec.touch_keyboard.provider = "sogou_hand"`。

### P05 · 底栏不可点

1. 全屏层 z-index 不得高于 `.toolbar`（竖屏 **50**）  
2. `body.kiosk-blocked .step-panel .toolbar { pointer-events:auto }`  
3. 泡泡 `getPlayBounds()` / CSS `bottom:96px` 避开底栏  
4. `btnNext.disabled` 须 `try/finally` 恢复
