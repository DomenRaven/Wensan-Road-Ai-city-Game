## 三、版本迭代（c07-11 → c07-14）

| 版本 | 问题 | 修复 |
|------|------|------|
| c07-11 | 切页 await hide 迟于新页输入 · 冷却阻断 show | `renderStep` 不 await · `dismissForNavigation` 导航 pointerdown |
| c07-12 | 新页需点 2–3 次 · hide 与 show 竞态 | 去掉 ensure 延迟 · 用户手势 force show |
| c07-13 | 泡泡页仍有 PowerShell 延迟 · 闪烁 | `tabtip_native.py` COM 单线程 · AbortController · warm |
| c07-14 | hide 误判 `already_hidden` 不关键盘 | `_tabtip_open` 状态跟踪 · 导航钮也触发 hide · COM 专用 worker |

## 五、展厅启动（必读）

```powershell
# 推荐：一键双服务
python .\05-工具脚本\launch_workshop.py

# 或手动
python -m http.server 8080 --bind 127.0.0.1   # 项目根目录
.\05-工具脚本\run_backend.ps1                  # API :8000
```

**常见异常**：浏览器只开 `http://127.0.0.1`（80 端口）→ `ERR_CONNECTION_REFUSED`。正确入口见上表。
