## 四、B1 碰撞泡泡 + 触控键盘（C-1 验收通过 · 2026-07-05）

### 4.1 泡泡实现要点

| 项 | 建议 |
|----|------|
| 渲染 | DOM + `requestAnimationFrame` · 非 Canvas（布局/触控更稳） |
| 图标 | HTML emoji 奖章 · `EduB1Intent.emoji(slug)` · **勿用** preview PNG |
| chip→genre | **`CHIP_TEXT_GENRE` 精确表优先** · 再 fallback `KEYWORD_MAP` |
| 竖屏 | `.step-panel` Grid 居中 · 泡泡层 `bottom:96px` · toolbar fixed |
| 缓存 | 改 JS/CSS 必 bump `index.html` `?v=` |

### 4.2 触控键盘（全 B 链标准）

| 必须 | 禁止 |
|------|------|
| class `edu-touch-input` + `EduTouchKeyboard.bind()` | 页面内自建 QWERTY/常用字面板 |
| `pointerdown` 同步 `focus` + `POST /kiosk/touch-keyboard/show` | `focusin` 重复 Toggle TabTip |
| 后端 :8000 运行 | 仅依赖浏览器 focus 唤起 TabTip |
| Windows 默认输入法 = 搜狗拼音（或微软拼音） | 假设 TabTip 自动中文 |

**搜狗软键盘**：无公开独立 exe（仅 `SoftKeyBoard.cupf`）；`SGTool --appid=softkeyboard` 实测失败。手写备选：`touch_keyboard.provider = "sogou_hand"`。

### 4.3 z-index 与 pointer-events

```text
.intent-bubble-field     z-index: 2  · pointer-events: none（子泡泡 auto）
#stepForm / 输入框        z-index: 8
body.edu-step-b1 .toolbar,
body.edu-step-b2 .toolbar  z-index: 50 · pointer-events: auto
body.kiosk-blocked .step-panel .toolbar → 仍 pointer-events: auto
```

### 4.4 展厅双服务

```powershell
python -m http.server 8080 --bind 127.0.0.1   # UI
.\05-工具脚本\run_backend.ps1                  # API + 键盘
```

入口：**http://127.0.0.1:8080/kiosk/edu/**（路径不变）

### 4.5 后续 C 窗勿破坏

- B2/B4 等新增 `<input>`/`<textarea>` 须接 `edu-touch-input` 标准（见技术规范 §八）
- 勿在 B1 之上叠加 z-index>50 的全屏 fixed 层（除非留底栏命中区）

### 5.2 C-2 · 展厅字号（页眉全局 + B2 内容）

**触发**：用户反馈竖屏远距离观看困难。

| 层 | 做法 | 禁止 |
|----|------|------|
| 页眉全局 | `:root` 定义 `--edu-header-brand` / `--edu-header-work-name` / `--edu-header-phase` / `--edu-header-action` 等 | 仅 `edu-step-b2` 写页眉覆盖（各步不一致） |
| 竖屏放大 | `body[data-orientation="portrait"]` 覆写同名变量 · `--edu-header-h: 140px` | 竖屏 B1/B2 再 `display:none` 品牌副标题 |
| B2 内容 | `body.edu-step-b2` 放大 subtitle / input / hint / chip / toolbar | 与页眉变量重复定义同一字号 |
| 高度联动 | `min-height: calc(100dvh - var(--edu-header-h))` 随变量走 | 写死 72px 头高 |

**变量一览**（`edu-styles.css` `:root`）：

```text
--edu-header-brand      品牌主标题
--edu-header-brand-sub  「文三路 AI 教育区 · 看得见的代码」
--edu-header-work-name  【品类】创作中 / 名《游戏名》
--edu-header-phase      创作 · 制作 · 试玩
--edu-header-action     ← 展厅快玩 · 重新开始
--edu-header-h          页眉最小高度（竖屏约 140px）
```

**经验**：后续 C-4~C-8 改字号优先调变量，B0–B7 自动同步。

### 5.6 C-4 · 验收热修（c04-02 ~ c04-06）

| 版本 | 问题 | 修复 |
|------|------|------|
| c04-02 | 题卡不够「小朋友向」 | 揭幕卡风 gradient shell · 触控字号 `edu-step-b4` |
| c04-03 | B3 字号未同步 · 提交钮过早出现 | `edu-step-dual-create` · `confirmedIndices` · 选答暂停+星星 |
| c04-04 | `[hidden]` 无效 · 选答后锁死 | `.b4-submit-btn[hidden]{display:none!important}` · `pickLocked`/`cardTransitioning` 双锁 |
| c04-05 | 赛车计时环过大 · widget 单一 · B2 IME | SVG 限 40px · 七款 per-q widget · `compositionend`/NFKC |
| c04-06 | 星星不在点击处 | `pointerFromEvent(ev)` · burst 相对 `.b4-card-inner` 定位 |

**经验**：

1. **hidden 按钮**必须加 `display:none!important`，否则被 `.btn { display:inline-flex }` 盖掉。
2. **过渡锁**分「选答暂停」与「切卡动画」两把锁，不可共用一个 `transitioning` 布尔。
3. **SVG widget**必须写死 `width/height`，勿依赖容器撑满。
4. **展厅 IME**：B2 名字要处理 `compositionend` + blur 提交 + 全角转半角。
5. **触控反馈**：星星爆发原点用 `clientX/clientY` 换算到题卡 inner 坐标。

### 5.11 C-6 · B2 保存名字 404 + session 自愈（c06-05）

| 项 | 做法 |
|----|------|
| 现象 | B2 点下一步 · `保存名字失败 - 404 Session not found` |
| 根因 | 后端重启丢 session · bootstrap 失败进 `demo-` · LAN 页访问但 `api_base=127.0.0.1` |
| 修复 | `EduSession.ensureSession()` 写前 GET 校验 · 404/demo 则 `POST /sessions` 重建 |
| LAN | `resolveApiBase()` 页面 host 非 localhost 时 API 跟同源 IP:8000 |
| 接入 | `edu-wizard.js` B2 子屏 A/B 写操作前 `await ensureSession()` |
| 文案 | 连不上后端 →「无法连接创作工坊，请检查网络或联系老师」 |

**经验**：

1. **凡写 session 的步骤**（B2 PATCH · wizard S0 · 证书上传）前应 `ensureSession()`，勿假设 bootstrap 后 session 永存。
2. **展馆多终端**访问时禁止写死 `127.0.0.1`；`kiosk_edu_spec.api_base` 可被 `resolveApiBase` 覆写为页面主机。
3. bootstrap 失败仍允许 UI 演示，但**写操作必须自愈或明确阻断**，避免 404 误报为「输入异常」。
