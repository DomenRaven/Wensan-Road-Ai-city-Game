## 一、用户故事

作为展厅触摸屏前的小孩，我希望**不用物理键盘**也能完成七款游戏的试玩，按钮够大、不容易误触，讲解员 B7 演示钮仍然可用。

## 二、出现时机

| 场景 | 行为 |
|------|------|
| B 链 B7 试玩 | workspace 注入 overlay · 与外置 Godot 窗同步显示 |
| A 链 S9 快玩 | 同 launcher · 同 overlay 注入 |
| 创作 B1–B6 | 不展示游戏内虚拟键 |

---

## 三、触控约束

| 项 | 规格 |
|----|------|
| 最小触区 | **48×48 px**（`kiosk_edu_spec.touch_constraints`） |
| 主操作 | ≤ **3** 个（面向 14 岁以下） |
| 视觉 | 半透明 · 不挡血量/分数等 HUD 核心信息 |
| 显隐 | 与游戏 HUD 同步（仿 fighting：`BattleHUD.visible` 或等价） |
| 输入 | 映射现有 `project.godot` Input Action · **不改 core** |

---

## 四、实现架构

```text
templates/_edu/{slug}_touch_overlay.gd     ← 新建（fighting 已有）
        ↓ copy on prepare_edu_workspace
workspace/core/{slug}_touch_overlay.gd
        ↓ patch main.tscn
CanvasLayer / {Slug}Touch 节点
        ↓
Input.action_press/release 或 模拟鼠标/触屏事件
```

**参考**：`fighting_touch_overlay.gd` · `platformer_touch_overlay.gd` · `edu_workspace._patch_main_tscn_*_touch`  
**经验手册**：[`7.4_P4-B触控覆盖_热修经验手册_v1.0.md`](./7.4_P4-B触控覆盖_热修经验手册_v1.0.md)

## 五、分品类要点

详见 [`7.4_七款触控映射表_v1.0.md`](./7.4_七款触控映射表_v1.0.md)。

| 类型 | 品类 | 关键技术 |
|------|------|----------|
| 虚拟键 | platformer · parkour · fighting | hold/tap → Action（推荐 `PanelContainer`+多点触控，见经验手册 §三） |
| 摇杆+瞄准 | survivor | 摇杆 → move_*；触区 → 模拟鼠标瞄准 |
| 滑动 | pingpong · shmup · racing | ScreenDrag → Action 或 warp_mouse |

---

## 六、edu_workspace 扩展规范

每款新增（仿 fighting）：

1. 常量 `{SLUG}_TOUCH_FILENAME`
2. `genre == "{slug}"` 时 `shutil.copy2` 到 `core/`
3. `_patch_main_tscn_{slug}_touch(main_path)` — 幂等（检测节点名已存在则跳过）

**禁止**：在本阶段重构为通用反射式 patch（保持每款显式分支，便于冻结与回归）。

## 七、冻结与解冻

| 品类 | 规则文件 | 收工后 |
|------|----------|--------|
| platformer | `frozen-platformer.mdc` | `freeze_platformer_snapshot.py` |
| parkour | `frozen-parkour.mdc` | `freeze_parkour_snapshot.py` |
| racing | `frozen-racing.mdc` | `freeze_racing_snapshot.py` |
| fighting | `frozen-fighting.mdc` | `freeze_fighting_snapshot.py` |
| shmup · pingpong | `frozen-shmup-pingpong.mdc` | `freeze_genre_snapshot.py` |
| survivor | 通常无单品类 frozen | 视 diff 决定 |

overlay 文件在 `_edu/` · 改 fighting **须用户书面解冻**。
