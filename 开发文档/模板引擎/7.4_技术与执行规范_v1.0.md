## 二、P4-B · overlay 技术规范

### 注入流程

```text
prepare_edu_workspace(genre, workspace)
  → copy templates/_edu/{slug}_touch_overlay.gd → workspace/core/
  → patch main.tscn 添加 CanvasLayer/{Slug}Touch
  → Godot launch 加载 workspace 工程
```

### 输入映射方式

| 类型 | 实现 |
|------|------|
| 虚拟键 hold | `Button.button_down/up` → `Input.action_press/release` |
| 虚拟键 tap | `Button.pressed` → `_pulse_action`（press + release） |
| 滑动 | `InputEventScreenDrag` / `MouseMotion` → Action 或 `Input.warp_mouse` |
| 模拟鼠标 | `Input.parse_input_event` 注入 `InputEventMouseButton/Motion` |

### survivor / shmup 特殊说明

- **survivor**：`player_survivor.gd` 用鼠标左键更新 `_shoot_angle` · overlay 须模拟鼠标事件，**不得**改 core
- **shmup**：`player_ship.gd` 在左键按住时读 `get_global_mouse_position().x` · overlay 须维持该语义

### edu_workspace patch 规范

- 幂等：检测 `name="{Slug}Touch"` 已存在则 return
- 节点挂 `CanvasLayer` 下 · `mouse_filter = 2`（IGNORE 根 · 子按钮 STOP）
- `load_steps` + `ext_resource` 递增（仿 fighting）
