## 三、虚拟键实现模式（★ 推荐 · 勿用 Button）

### 3.1 为何不用 `Button`

| 问题 | 原因 |
|------|------|
| 鼠标无法方向+跳同时按 | 单键硬件限制 + 拖移会 `button_up` 方向键 |
| 跳跃偶发失效 | `call_deferred` 释放过早，`is_action_just_pressed` 未命中物理帧 |
| 触屏误触 | Button 焦点互斥不如按 `touch_index` 独立追踪稳 |

### 3.2 推荐实现

1. **`PanelContainer` + `gui_input`**，按 `InputEventScreenTouch.index` 追踪每指  
2. **方向类 action**：`press` 按住 · `release` 松手  
3. **跳跃类 action**（`is_action_just_pressed`）：`press` 后 **下一 `_physics_process`** 再 `release`  
4. **`NOTIFICATION_WM_WINDOW_FOCUS_OUT`**：释放全部 action，防失焦卡键  

参考：`templates/_edu/platformer_touch_overlay.gd`

### 3.3 tap / hold 与 core 对齐

施工前 **必读** `templates/{slug}/core/player_*.gd`：

| core  API | overlay 语义 | 示例 |
|-----------|-------------|------|
| `is_action_just_pressed` | tap（物理帧脉冲） | platformer `jump` · parkour `jump` |
| `is_action_pressed` | hold | platformer `move_*` · parkour `skill`（滑铲） |
| `get_action_strength` | hold（可并存多键） | fighting `p1_left` |
