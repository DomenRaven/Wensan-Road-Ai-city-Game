## 四、问题与决策（11 项）

详见 [`7.4_P4-C01_B1泡泡UI_施工足迹与问题记录_v1.0.md`](../7.4_P4-C01_B1泡泡UI_施工足迹与问题记录_v1.0.md) §二。

| 类别 | 代表问题 | 最终方案 |
|------|----------|----------|
| 布局 | 竖屏底栏不可见/不可点 | toolbar fixed · z-index 50 · 泡泡层 bottom 留白 |
| 图标 | 格斗误显乒乓球 | `CHIP_TEXT_GENRE` 精确表优先于 KEYWORD_MAP |
| 键盘 | 只能英文 · 不稳定 · 无法直接调搜狗 exe | TabTip + 切中文 IME；搜狗设为默认输入法；禁止页面模拟键 |
| 运维 | 8080 未开导致 UI 打不开 | 双服务：`http.server 8080` + `run_backend.ps1` |

**设计限制（已确认接受）**：搜狗「软键盘」无独立 `.exe`，无法像 TabTip 一样单独 API 调用；展厅方案为 **搜狗拼音作默认 IME + TabTip 触屏键位**。
