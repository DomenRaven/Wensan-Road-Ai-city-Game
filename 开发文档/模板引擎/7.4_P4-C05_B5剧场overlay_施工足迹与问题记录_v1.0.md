## 三、修复方案摘要

### P01 · overlay 挂载顺序

```text
code-theater.start():
  1. classList.add("code-theater-stage") + data-theater-genre
  2. EduCodeViewer.mount(codeContainer)   ← 会清空容器
  3. EduTheaterOverlays.start(genre, …)   ← 必须在 mount 之后
```

### P06 · 跑酷紫色条纹

```css
.code-theater-stage[data-theater-genre="parkour"]::after {
  content: none;
  display: none;
}
```

### P07 · 肉鸽粒子

```text
spawnParticle(): getBoundingClientRect() 算像素路径
WAAPI 仅 animate transform + opacity（勿 animate left/top）
每波 5–8 个 · 10 色 · 0.7–1.4s 间隔
```
