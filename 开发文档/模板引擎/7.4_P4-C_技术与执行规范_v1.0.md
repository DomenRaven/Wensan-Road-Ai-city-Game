## 二、B2 子状态机（UI-C01 + 揭幕触发）

v1.1 的 `B2` 单屏游戏名 → 7.4 改为 **B2 内两屏**（不新增 STEPS 枚举，用 `b2SubStep`）：

```text
b2SubStep = "creator"   → 「你的名字是？」
b2SubStep = "gameName"  → 「给游戏起个名字」
b2SubStep = "done"      → 触发揭幕（UI-C02）→ 再 stepIndex++ 到 B3
```

| 字段 | 校验 | 存储 |
|------|------|------|
| `creatorName` | 1–8 字 · `/^[\u4e00-\u9fa5a-zA-Z0-9]+$/` 或放宽含· | 前端 + 后端 |
| `displayName` | 沿用 `EduB2Name.isValid` | 现有 `display_name` |

**后端**（推荐）：

```python
# SessionRecord 新增
creator_name: str = ""
```

```http
PATCH /sessions/{session_id}
Content-Type: application/json

{ "creator_name": "小明", "display_name": "赛车之王" }
```

若 PATCH 不存在，施工窗在 `routers/sessions.py` 扩展；**勿**塞进 `creative/answers`。

## 三、揭幕时序（UI-C02）

| 阶段 | ms | DOM |
|------|-----|-----|
| T0 遮罩淡入 | 0–400 | `#forgeRevealOverlay` opacity 0→0.72 |
| T1 卡片+烟花入 | 200–600 | `.forge-reveal-card` scale 0.9→1 · canvas 烟花 |
| T2 停留 | 1200 | 文案可读 |
| T3 卡片淡出 | 400 | card opacity→0 |
| T4 遮罩淡出 | 600 | overlay 移除 · `genre-theme.apply(slug)` |
| **总时长** | ~2.6s | `await ForgeReveal.play({creator, displayName, genre})` |

揭幕期间 `setUiEnabled(false)` · 完成后 resolve 再进入 B3。

**文案模板**（`kiosk_edu_spec.forge_reveal`）：

```json
{
  "card_template": "开始制作{creator}的{game}游戏！",
  "firework_count": 12,
  "skip_on_reduced_motion": true
}
```

## 六、排行榜 API（UI-C06）

### 提交

```http
POST /leaderboard/{genre}/entries
Content-Type: application/json

{
  "session_id": "…",
  "creator_name": "小明",
  "display_name": "赛车之王",
  "score": 1280,
  "elapsed_ms": 45200,
  "metric": "score"
}
```

### 查询

```http
GET /leaderboard/{genre}?limit=10&metric=score
→ { "entries": [ { "rank", "creator_name", "display_name", "score", "elapsed_ms", "created_at" } ] }
```

**存储**：Redis sorted set `lb:{genre}:{metric}` 或内存 dict（与 `SessionStore` 同进程）；**本期不持久化跨重启**亦可接受，文档注明即可。

### 窗关闭检测（前端）

```javascript
// edu-wizard.js B7 · 已有 launchStatusPollTimer 扩展
const st = await api(`/sessions/${id}/play/status`);
if (prevRunning && !st.running && LEADERBOARD_GENRES.has(genre)) {
  await EduLeaderboard.showAfterRun(sessionId, genre);
}
```

### hooks（仅 `_edu`，不改 core）

```gdscript
# platformer_hooks.gd 示例
func _on_victory_or_gameover() -> void:
    _bridge.emit_run_complete(score, elapsed_ms)
```

`edu_action_bridge` 扩展 `run_complete` action，payload 写入 `.edu_actions.jsonl` 末行 JSON 扩展字段；submit API 读 workspace 或 wizard 缓存。

## 八、触控软键盘（展厅无物理键盘 · 全 B 链标准）

**场地约束**：展厅 kiosk **仅有触摸屏、无物理键盘**；须唤起 **操作系统 IME 软键盘**（微软拼音等），**禁止**页面内自建模拟键位。

### 实现

| 项 | 规格 |
|----|------|
| 模块 | `kiosk/edu/touch-keyboard.js` → `EduTouchKeyboard.init()` / `.bind()` |
| 行为 | `pointerdown`/`touchstart` 同步 `focus` · `POST /kiosk/touch-keyboard/show` 唤起 TabTip |
| 后端 | `backend/app/routers/kiosk.py` · `05-工具脚本/show_tabtip.ps1` |
| 绑定 | class **`edu-touch-input`** · 各 step `render()` 后 `bind(formEl)` |
| 禁止 | `#eduTouchKeyboard` 自建面板 · `pointerdown preventDefault` 抢焦点 |

### Windows 展厅部署（运维必做）

1. 设置 → 键入 → **没有键盘时显示触摸键盘** = 开  
2. 安装并默认 **中文输入法**  
3. Edge Kiosk 全屏模式  

详见 [`7.4_P4-C01_B1泡泡UI_施工足迹与问题记录_v1.0.md`](./7.4_P4-C01_B1泡泡UI_施工足迹与问题记录_v1.0.md) §三 P04。

### 适用范围

B1 `#intentInput` · B2 `#creatorInput` · B2 `#nameInput` · 后续 B 链文本框同上。

### 验收

- [ ] 触屏点输入框 → **系统** TabTip/IME 弹出（非页面内假键盘）
- [ ] 可拼音输入中文并上屏
- [ ] 输入时底栏按钮仍可点击
