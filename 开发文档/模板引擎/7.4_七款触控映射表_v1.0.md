## 〇、通用规则

| 项 | 规则 |
|----|------|
| 文件命名 | `templates/_edu/{slug}_touch_overlay.gd` |
| 注入 | `edu_workspace.py` copy 至 workspace `core/` + patch `main.tscn` |
| 节点命名 | `{Slug}Touch`（如 `PlatformerTouch`） |
| 按钮尺寸 | ≥ **48×48 px**（建议 56×56） |
| 主操作数 | ≤ **3**（K12 规则） |
| 样式 | 半透明深蓝底 · 橙边 · 与 fighting 一致 |
| core | **禁止修改** `templates/{slug}/core/**` |
