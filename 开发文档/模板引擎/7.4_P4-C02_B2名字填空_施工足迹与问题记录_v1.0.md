## 三、修复方案摘要

### P01 · B2 竖屏底栏

```text
body.edu-step-b1 .step-panel, body.edu-step-b2 .step-panel  → 同网格
body.edu-step-b1[data-orientation=portrait] .toolbar,
body.edu-step-b2[data-orientation=portrait] .toolbar         → fixed bottom z-index 50
```

**经验**：凡 B1–B2 单栏步，须独立 body class（`edu-step-b1` / `edu-step-b2`），**勿**进入 B2 时只删 B1 class。

### P05/P06 · 展厅字号（全局页眉 + B2 内容）

| 层 | 变量/选择器 | 说明 |
|----|-------------|------|
| 全局页眉 | `:root --edu-header-brand` 等 | B0–B7 统一 · 竖屏 `body[data-orientation=portrait]` 再放大 |
| B2 内容 | `body.edu-step-b2 .step-subtitle` 等 | 主标题/输入/hint/芯片/底栏 |
| 高度 | `--edu-header-h` 96→140px（竖屏） | 与 `calc(100dvh - var(--edu-header-h))` 联动 |

**经验**：页眉字号用 **CSS 变量** 一次定义、全链继承；避免按步骤写多套覆盖。

### P02 · PATCH 契约

```javascript
// 子屏 A 下一步 · 失败不前进
await EduSession.api(`/sessions/${id}`, { method: "PATCH", body: { creator_name } });
// catch → showValidationError + return
```
