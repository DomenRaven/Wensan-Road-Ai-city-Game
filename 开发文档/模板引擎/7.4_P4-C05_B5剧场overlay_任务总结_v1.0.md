## 四、关键问题与解法

1. **overlay 不显示** → `EduCodeViewer.mount()` 会清空容器，overlay 必须在 mount **之后**启动。
2. **B5 字号过小** → 使用 `body[data-edu-phase="build"]` 放大工作区名/文件树/代码。
3. **跑酷紫色条纹** → 非 overlay 模块，而是 `.code-theater-stage::after` 网格 + 紫色 accent；用 `data-theater-genre="parkour"` 禁用。
4. **肉鸽粒子不可见** → WAAPI 动画 `left/top` 不可靠；改用 `transform` 像素路径 + 提高频率/色数。
5. **缓存混版** → theater 相关脚本/CSS 全链统一 bump 至 `c05-08`。
