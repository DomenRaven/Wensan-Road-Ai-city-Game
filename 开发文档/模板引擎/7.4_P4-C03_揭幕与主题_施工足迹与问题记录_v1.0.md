## 三、修复方案摘要

### P01 · B2 子屏 B 文案（c03-02）

```text
edu-wizard.js  gameName 分支：
  stepTitle     → 「你好，{creatorName}！」
  stepSubtitle  → hidden（删除「起个好听的名字吧」）

b2-name.js：
  引导语 → 「让我们制作一个{genreLabel}小游戏吧！」（无【】· 无左侧图标）
  label  → 「你想让它叫什么名字呢？」
```

### P02 · 揭幕视觉（c03-02）

| 层 | 实现 |
|----|------|
| 卡片 | `.forge-reveal-card` 渐变边框 · 内层光晕 · ✨ 角标 · 品类 emoji · 文字渐变 + 扫光 |
| 背景 | overlay 多层 radial-gradient + 24 颗 CSS 闪烁星 |
| 烟花 | Canvas 5 轮连爆 · 星形/圆点粒子 · 拖尾 · 光晕 |

### P03 · UI 背景统一（c03-03 · 用户验收决策）

```text
保留：forge-reveal 读 spec.genre_themes.{slug}.accent 仅用于揭幕卡 --forge-accent
移除：body[data-genre-theme] 全部 CSS · forge-reveal 不再调用 apply()
保留：genre-theme.js themeFor() · resetWizard clear() 清理残留 attribute
```

**经验**：品类 token 写入 spec 供局部装饰（揭幕卡/B4 widget/B5 剧场）；**全页 UI 背景维持 v1.1 蓝白**，除非甲方另行要求。

### P04 · 阻塞契约

```javascript
// edu-wizard.js B2 子屏 B
await window.EduForgeReveal?.play({ creatorName, displayName, genre, genreLabel });
// 上述 Promise resolve 前不得 stepIndex++ 进 B3
```
