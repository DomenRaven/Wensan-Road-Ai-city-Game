## 三、修复方案摘要

### P02 · 隐藏提交钮

```css
.dual-toolbar .b4-submit-btn[hidden] {
  display: none !important;
}
```

```javascript
// confirmedIndices 满且末题才 show
btn.hidden = !isReadyToSubmit();
```

### P03 · 双锁

```text
pickLocked       → 选答暂停 520ms 期间
cardTransitioning → 卡片飞出/飞入 280ms 期间
advanceForward 前必须 pickLocked=false
```

### P07 · 点击对齐星星

```javascript
playPickFeedback(shell, optionCard, pointerFromEvent(ev));
// burst.style.left/top = 相对 .b4-card-inner 的 client 坐标
```
