# 7.4 · 展厅正式落地 · 需求规格 v1.0

> **起算**：2026-07-04  
> **基线**：GitHub `main` @ `6b979da` · tag **`v1.1`**  
> **前置**：P3 蓝白 UI · 横竖屏 · Godot 外置窗 Win32 归位 · RECIPE 配方+证书 已收工  
> **目标**：触摸屏展厅环境可完整游玩 + 探索 Godot 内嵌 + UI 进一步美化（细则待甲方）

---

## 一、产品一句话

**文三路 AI 游戏创作工坊（GameForge K12）** 在 v1.1 基础上，面向 **触摸屏展厅** 完成三项落地：七款游戏 **无键盘可玩**、试玩区探索 **Godot 画面内嵌**、Kiosk **视觉进一步美化**。

---

## 二、甲方 / 产品目标

| # | 需求 | 代号 | 验收 |
|---|------|------|------|
| P4-R1 | 七款无物理键盘可正常试玩 | **P4-B** | 竖屏 1080×1920 实机各玩 ≥1 分钟 |
| P4-R2 | 触控按钮/触区 ≥48px · 主操作 ≤3 | P4-B | `kiosk_edu_spec.touch_constraints` 对齐 |
| P4-R3 | 试玩时 Godot 出现在 Kiosk 页面内 | **P4-A** | Spike 选型 + 实现后 zone 有真实画面 |
| P4-R4 | Kiosk 视觉进一步美化 | **P4-C** | 甲方细则到位后逐项验收 |
| P4-R5 | 不破坏 v1.1 已交付能力 | 硬约束 | P3-3 外置窗降级保留 · RECIPE 冻结 |
| P4-R6 | 不改动模板 core 主线 | 硬约束 | `git diff templates/*/core/` 为空 |

---

## 三、优先级（用户确认 2026-07-04）

```text
P4-B  七款全触控          ← 第一优先
P4-A  Godot 窗口内嵌      ← 第二优先（B 线可并行 Spike）
P4-C  UI 进一步美化       ← 第三优先（等甲方细则）
```

## 四、范围

### 在范围

| 线 | 路径（典型） |
|----|-------------|
| P4-B | `templates/_edu/*_touch_overlay.gd` · `edu_workspace.py` |
| P4-A | `godot_launcher.py` · `godot_window_layout.py` · `kiosk/edu/*` · `play.py` |
| P4-C | `kiosk_edu_spec.json` · `kiosk/edu/*.css` · `kiosk/styles.css`（细则后） |
| 文档 | 本系列 · 整合清单 · 评审记录 · 工作状态 §八 |

### 不在范围

- `templates/{slug}/core/**` 修改（除非用户书面解冻）
- RECIPE 问卷/证书逻辑与文案
- LLM 接入 · 联机 · 存档 · 内购
- 删除 P3-3 外置窗逻辑（须 Spike 评估后决策）

### 与 v1.1 关系

| v1.1 已交付 | 7.4 动作 |
|-------------|----------|
| 外置 Godot + Win32 贴边 | P4-A 探索内嵌；未选型前 **保留** |
| fighting 触控 overlay | P4-B7 抛光 + 六款补齐 |
| 蓝白 UI + 横竖屏 | P4-C 在基线上美化 |
| RECIPE 冻结 | **禁止** 顺带改问卷/证书 |
