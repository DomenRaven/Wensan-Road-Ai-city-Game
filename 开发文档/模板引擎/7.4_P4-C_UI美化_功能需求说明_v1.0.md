## 一、用户故事

作为 14 岁以下展厅儿童，我希望从开始选游戏到拿到证书，全程像「为自己的小游戏开机」一样好玩：有泡泡、烟花、专属颜色和趣味证书，打得好还能上排行榜。

作为讲解员，我希望孩子在 B2 报出名字后，大屏有仪式感揭幕，且进入配方后每款游戏的界面风格与游戏类型一致，便于讲解「你的配方正在变成这款游戏」。

## 三、UI-C02 · 揭幕过渡 + 品类主题（FRS-P4-C-02）

### 3.1 揭幕序列

甲方原话：「屏幕暗屏并弹出开始制作XX的XX游戏！卡片，配上烟花特效，然后亮度恢复，同时卡片淡化。」

| 帧 | 视觉 | 技术 |
|----|------|------|
| 1 | 全屏半透明黑遮罩 | `#forgeRevealOverlay` fixed inset 0 |
| 2 | 中央大卡片 + 文案 | `.forge-reveal-card` · 白底圆角 · `genre` 色左边条 |
| 3 | 烟花 | Canvas 粒子或 CSS 多向 `box-shadow` 爆发 |
| 4 | 卡片淡出、遮罩消失 | 移除 DOM · 恢复 `pointer-events` |
| 5 | 主题生效 | `GenreTheme.apply(genre)` |

**阻塞**：揭幕 `await` 完成前不得进入 B3（防连点下一步）。

### 3.2 品类主题

从 **B3 双栏** 起至 B7，页面应用 `body[data-genre-theme="{slug}"]`。

| 作用域 | 随主题变化 |
|--------|------------|
| 阶段条激活色 | `--genre-accent` |
| 步骤面板底 | `--genre-surface` |
| 卡片边框/选中 | `--genre-accent-light` |
| ambient 装饰 | `pattern` 类名切换 CSS 背景 |
| **不变** | 代码区语法高亮 · RECIPE 配方文字 |

**配置样例**（`kiosk_edu_spec.json` 追加）：

```json
"genre_themes": {
  "racing": {
    "accent": "#ea580c",
    "accent_light": "#ffedd5",
    "surface": "#fff7ed",
    "pattern": "checkered",
    "emoji": "🏎️"
  }
},
"forge_reveal": {
  "card_template": "开始制作{creator}的{game}游戏！",
  "firework_count": 12
}
```

完整七款见映射表 §一。

### 3.3 文件

| 文件 | 改动 |
|------|------|
| `kiosk/edu/forge-reveal.js` | **新建** `window.ForgeReveal.play(opts)` |
| `kiosk/edu/genre-theme.js` | **新建** `apply` / `clear` |
| `kiosk/edu/edu-styles.css` | `[data-genre-theme]` 规则 · 揭幕层 |
| `config/kiosk_edu_spec.json` | `genre_themes` · `forge_reveal` |

## 四、UI-C03 · B4 卡片式配方（FRS-P4-C-03）

### 4.1 交互规格

甲方原话：「列表式改成卡片式逐个弹出，每个小问题卡片配上合适流畅的小动画，要有流畅的卡片轮回动画和进度条。」

| 项 | 规格 |
|----|------|
| 布局 | 单题占 `stepForm` 或 dual 左栏主区域 80% 宽 |
| 导航 | 选答后自动下一题；末题后点「下一步」提交（与 v1.1 一致） |
| 回退 | 「上一步」在 B4 内回到上一题卡；第一题上一步回 B3 |
| 进度 | 顶部细条 + 文字 `3 / 5` |
| 题面 | 原 `question.prompt` 原文 + 下方 `option-card` 三选一 |
| 装饰 | `B4_WIDGET_REGISTRY[genre][qid]` 见映射表 §二 |

### 4.2 与 RECIPE 边界

- `EduB4Creative.loadTemplate` · `validate` · `submitAnswers` **不改签名**
- `question.id` / `options[].id` / `tuning_path` **只读**

### 4.3 文件

| 文件 | 改动 |
|------|------|
| `kiosk/edu/steps/b4-card-flow.js` | **新建** 轮播+进度 |
| `kiosk/edu/steps/b4-creative.js` | `render` 委托 card-flow |
| `kiosk/edu/edu-styles.css` | `.b4-card-flow*` 动画类 |

### 4.4 验收

- [ ] fighting 4 题 · 其他 6 款 5 题进度正确
- [ ] 选极端 tuning 后 B7 体感仍与 v1.1 一致
- [ ] 动画期间按钮禁用

## 九、非功能需求

| 项 | 要求 |
|----|------|
| 性能 | 单页 JS 新增 <150KB（未压缩） |
| **触控输入** | 展厅 **无物理键盘** · 唤起 **OS IME**（`touch-keyboard.js`）· **禁止**自建模拟键位 · 见技术规范 §八 |
| 无障碍 | 揭幕/排行榜 `aria-modal` · 焦点陷阱 |
| 横竖屏 | 泡泡 stage 高度竖屏 ≥180px · 证书/GIF 竖屏可滚动 |
| 重置 | `btnReset` 清 creatorName · theme · overlay 实例 |
