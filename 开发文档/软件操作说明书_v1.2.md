## 一、产品是什么

在触控一体机上，观众用自然语言选游戏类型、填写名字与手感配方，系统生成可试玩的 Godot 小游戏，并展示代码、证书与今日排行榜。

| 项 | 内容 |
|----|------|
| 主入口 | B 链教育创作：`http://127.0.0.1:8080/kiosk/edu/` |
| 快玩入口 | A 链：`http://127.0.0.1:8080/kiosk/` |
| 适用对象 | 约 6–14 岁（操作 ≤3 键 / 触屏） |
| 单次体验 | 约 8–12 分钟 |
| 游戏品类 | **7 款**：横版闯关、街机飞机、生存升级、乒乓球、格斗对战、跑酷、欢乐赛车 |

## 二、每日开馆 / 闭馆

### 2.1 开馆（推荐）

1. 确认本机已安装 **Python 3.11+**、**Godot 4.6 Standard**，且 `backend\.env` 中 `GODOT_PATH` 正确。  
2. 双击仓库根目录 **`启动游戏工坊.exe`**（或运行下方命令）。  
3. 等待黑色控制台提示「服务已就绪」。  
4. 浏览器自动打开 B 链；建议 **Edge/Chrome 全屏（F11）**。  
5. 自检：能进入 B1 泡泡页、点输入框可出系统触控键盘（触屏机）。

```powershell
cd <解压后的项目根目录>
.\启动游戏工坊.exe
# 或不自动开浏览器：
.\启动游戏工坊.exe --no-browser
```

### 2.2 闭馆

1. 在启动器控制台按 **Enter**（或关闭该窗口）→ 停止由本启动器拉起的服务。  
2. 关闭浏览器全屏页。  
3. 可选：清理 `workspace\` 下过期会话目录（磁盘紧张时）。

## 三、观众操作流程（B 链 · 讲解员话术）

| 步骤 | 屏幕 | 观众做什么 | 讲解员注意 |
|------|------|------------|------------|
| B0 | 开馆连接 | 等待加载 | 失败则检查 API :8000 |
| B1 | 想玩什么 | 点彩色泡泡或打字描述 | 触控键盘点输入框唤起 |
| B2 | 名字 | 先填「你的名字」再起游戏名 | 1–8 字 |
| 揭幕 | 烟花卡 | 观看过渡 | 「开始制作某某的某某游戏」 |
| B3–B4 | 配方卡片 | 逐题选手感 | 一题一卡，可上一步 |
| B5 | 代码剧场 | 观看「AI 写代码」 | 可跳过等待 |
| B6 | 证书 + 试玩 | 保存证书 PNG；点开始试玩 | Godot 外置窗弹出 |
| B7 | 边玩边看代码 | 触屏玩；可点演示钮 | 关窗后弹出今日榜 |

**七款触屏操作摘要**

| 品类 | 触屏操作 |
|------|----------|
| 横版闯关 | 左下左右移动 · 右下跳跃 |
| 跑酷 | 跳跃 · 滑铲 |
| 生存升级 | 摇杆移动 · 触区瞄准射击 |
| 乒乓球 | 拖动球拍上下 |
| 街机飞机 | 拖动战机横向 |
| 格斗对战 | 方向 + 拳脚虚拟键 |
| 欢乐赛车 | 底部左右滑动转向 |

## 五、端口与地址（必记）

| 端口 | 服务 | 地址 |
|------|------|------|
| **8000** | FastAPI 后端 | http://127.0.0.1:8000 · 文档 `/docs` · 健康 `/health` |
| **8080** | Kiosk 静态页 | http://127.0.0.1:8080/kiosk/edu/ |
| **6379** | Redis（可选） | 本机 TCP；不可用则内存会话 |
| 9080 | Nginx 反代（可选） | 局域网多终端时使用 |

> **重要**：B 链必须从 **`http://127.0.0.1:8080/kiosk/edu/`** 进入，不要只开 `127.0.0.1` 或只开 `:8000`。

## 六、现场故障速查

| 现象 | 处理 |
|------|------|
| 页面打不开 | 确认 exe 已启动；访问 :8080；防火墙未拦 |
| 一直加载 / API 失败 | 查 `http://127.0.0.1:8000/health`；看控制台报错 |
| 点试玩没反应 / 503 | 检查 `backend\.env` 的 `GODOT_PATH` 是否为本机 Godot exe |
| Godot 窗跑到别处 | 横屏应贴右半；可手动拖回；竖屏贴下半 |
| 触控键盘不弹 | 确认 Windows 触屏/触摸键盘；从 :8080 进 B 链；API 正常 |
| 关游戏不弹榜 | 须**关掉 Godot 窗口**；乒乓球须打完一整局 |
| 证书扫码失败 | 公网域名未配属正常；仍可用「保存证书」本机 PNG |
| 端口被占用 | `netstat -ano \| findstr ":8000"` / `":8080"` 结束占用进程后重启 |

## 七、安全与内容边界

- 面向未成年人：无暴力血腥恐怖内容。  
- 勿改 `templates/*/core/` 预制逻辑。  
- 勿把含密钥的 `backend\.env` 外传。  
- 日榜数据在本机 `backend\data\`（若生成），可按日清理。
