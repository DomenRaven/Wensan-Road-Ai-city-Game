## 1. 立项动机与选型

### 1.1 为何采用「分层预言机」而非换 Judge

| 候选 | 结论 |
|------|------|
| 推翻 HF-14 改 LLM 自评 | **否**（与 G11/G12/HF-14 冲突；Reflexion 无 oracle 会自我确认） |
| 完整 OpenHands QA / 真机帧 | **P2 可选**（成本高） |
| **HF-14 延续：L1 修 + L2 表现谓词 + Observe** | **是**（主路径） |

参考：

- ReAct（Yao et al.）：Thought–Act–**Observe**  
- Reflexion（Shinn et al.）：反思须挂外部 oracle  
- Anthropic *Building Effective Agents* / *Harness for long-running apps*：评价标准清晰；契约 + 真点验 UI  
- OpenHands *Verification Stack*：分层验证；本窗先做静态场景谓词层  
- Vera / evidence-grounded verification：用环境终态判定，不信口头成功
