### §1 · 防火墙 8000 / 8080（核对 · 已完成可跳过创建）

```powershell
# 【查看】GameForge 防火墙规则
Get-NetFirewallRule -DisplayName "GameForge*" |
  Format-Table DisplayName, Enabled, Direction, Action

# 【若尚无规则则创建】重复执行报「已存在」可忽略
if (-not (Get-NetFirewallRule -DisplayName "GameForge API 8000" -ErrorAction SilentlyContinue)) {
  New-NetFirewallRule -DisplayName "GameForge API 8000" `
    -Direction Inbound -Protocol TCP -LocalPort 8000 -Action Allow -Profile Any
}
if (-not (Get-NetFirewallRule -DisplayName "GameForge Kiosk 8080" -ErrorAction SilentlyContinue)) {
  New-NetFirewallRule -DisplayName "GameForge Kiosk 8080" `
    -Direction Inbound -Protocol TCP -LocalPort 8080 -Action Allow -Profile Any
}

# 【查看】8000/8080 是否在监听；LocalAddress 含 0.0.0.0 表示局域网可访问
Get-NetTCPConnection -LocalPort 8000,8080 -State Listen -ErrorAction SilentlyContinue |
  Select-Object LocalAddress, LocalPort, State
```

| 期望 | 说明 |
|------|------|
| 两条 GameForge 规则 `Enabled=True` `Action=Allow` | 8000 API · 8080 Kiosk |
| Listen 行含 `0.0.0.0` | 若仅 `127.0.0.1`，见 **§5** 改用 `0.0.0.0` 重启 |

### §2 · 创建 workspace SMB 共享（核对 · 已完成可跳过创建）

```powershell
$WorkspacePath = "E:\project\GameForge-K12\workspace"
$ShareName     = "GameForgeWorkspace"
$ServerIp      = "10.71.121.18"

# 【检查】目录存在
Test-Path $WorkspacePath

# 【查看】当前内容（users\ 可能为空，学生登录开局后才有 users\{uid}\{sid}）
Get-ChildItem $WorkspacePath -ErrorAction SilentlyContinue
Get-ChildItem (Join-Path $WorkspacePath "users") -ErrorAction SilentlyContinue |
  Select-Object -First 5 Name

# 【创建共享】已存在则跳过
if (-not (Get-SmbShare -Name $ShareName -ErrorAction SilentlyContinue)) {
  New-SmbShare -Name $ShareName `
    -Path $WorkspacePath `
    -ChangeAccess "Users" `
    -FullAccess "Administrators"
}
# 若报 Users 组不存在，改为机房实际组名，或临时 -ChangeAccess "Everyone"（仅内网短期）

Get-SmbShare -Name $ShareName | Format-Table Name, Path, Description

# 【本机 UNC 测试】
Test-Path "\\$ServerIp\$ShareName"
Get-ChildItem "\\$ServerIp\$ShareName" -ErrorAction SilentlyContinue | Select-Object -First 8 Name
```

| 期望 | 说明 |
|------|------|
| `Test-Path $WorkspacePath` → `True` | 共享源目录 |
| `Get-SmbShare` 路径 = 上述 workspace | 共享名 `GameForgeWorkspace` |
| UNC `\\10.71.121.18\GameForgeWorkspace` 可列目录 | 与本地 listing 一致 |

**路径换算（学生机脚本用）：**

```text
E:\project\GameForge-K12\workspace\users\{uid}\{sid}  →  Z:\users\{uid}\{sid}
```

**NTFS 逐用户 ACL**：理想态每用户只能访问自己的 `users\{uid}\`；首课若 IT 来不及，至少保证共享仅内网可达（风险见上线清单 §3.3）。

### §2.5 · 发布 Godot 到 workspace 共享（学生机安装源 · 服务器做一次）

> **已确认（2026-07-21）** 服务器 Godot 路径：`C:\Godot\Godot_v4.6.3-stable_win64.exe`

```powershell
Get-Item $GodotSrc -ErrorAction SilentlyContinue | Select-Object FullName, Length, LastWriteTime

# 【发布】复制到 workspace 共享目录（Z: 下可见）
New-Item -ItemType Directory -Force -Path (Split-Path $GodotDest) | Out-Null
Copy-Item $GodotSrc $GodotDest -Force

# 【验证】本地 + UNC
Test-Path $GodotDest
Get-Item $GodotDest | Select-Object FullName, Length
Test-Path "\\10.71.121.18\GameForgeWorkspace\_tools\Godot\Godot_v4.6.3-stable_win64.exe"
```

| 期望 | 说明 |
|------|------|

| `$GodotDest` 约 130MB+ | 复制成功 |
| UNC `_tools\Godot\...exe` 可读 | 学生机映射 Z: 后可拷 |

### §3 · SMB 防火墙（学生机映射 Z: 前 · 必做）

```powershell
# 【中文系统】
Enable-NetFirewallRule -DisplayGroup "文件和打印机共享"

# 【英文系统若上句报错，改用】
# Enable-NetFirewallRule -DisplayGroup "File and Printer Sharing"

# 【验证】入站规则已启用（节选）
Get-NetFirewallRule -DisplayGroup "文件和打印机共享" -ErrorAction SilentlyContinue |
  Where-Object { $_.Direction -eq "Inbound" -and $_.Enabled -eq $true } |
  Select-Object -First 5 DisplayName, Enabled, Action

# 【445 监听】
Get-NetTCPConnection -LocalPort 445 -State Listen -ErrorAction SilentlyContinue |
  Select-Object LocalAddress, LocalPort, State
```

| 期望 | 说明 |
|------|------|
| 多条入站规则 `Enabled=True` | SMB 文件共享 |
| 445 处于 Listen | 服务器接受 SMB 连接 |

### §4 · 配置核对 + 健康检查与服务状态

```powershell
$Root     = "E:\project\GameForge-K12"
$ServerIp = "10.71.121.18"

# --- 4.1 关键配置（不打印 Key 明文）---
$envFile = Join-Path $Root "backend\.env"
Get-Content $envFile | Select-String -Pattern "^(PLAY_LAUNCH_MODE|MAX_SESSIONS|GODOT_PATH|LLM_API_KEY)=" |
  ForEach-Object {
    if ($_ -match "^LLM_API_KEY=(.+)$") {
      $v = $Matches[1].Trim()
      if ($v -and $v -notmatch "^(<|your_|changeme)") { "LLM_API_KEY=***已设置***" } else { "LLM_API_KEY=***空或未填***" }
    } else { $_ }
  }

$spec = Get-Content (Join-Path $Root "config\kiosk_edu_spec.json") -Raw | ConvertFrom-Json
Write-Host "kiosk api_base = $($spec.api_base)"
# 期望: http://10.71.121.18:8000（若仍是 127.0.0.1，学生机浏览器调 API 会失败）

# --- 4.2 本机 health / Kiosk ---
$h = Invoke-RestMethod http://127.0.0.1:8000/health
$h | Select-Object status, store_ok, max_sessions, play_launch_mode, active_sessions
(Invoke-WebRequest http://127.0.0.1:8080/kiosk/edu/ -UseBasicParsing).StatusCode

# --- 4.3 LAN IP（模拟学生机）---
(Invoke-WebRequest "http://${ServerIp}:8080/kiosk/edu/" -UseBasicParsing).StatusCode
Invoke-RestMethod "http://${ServerIp}:8000/health" |
  Select-Object status, max_sessions, play_launch_mode, store_ok

# --- 4.4 端口绑定 ---
Get-NetTCPConnection -LocalPort 8000,8080 -State Listen -ErrorAction SilentlyContinue |
  Select-Object LocalAddress, LocalPort, State
```

| 期望 | 说明 |
|------|------|
| `play_launch_mode` = `local_share` | 机房 S2-路B |
| `max_sessions` ≥ 70 | 与 `.env` 一致 |
| `LLM_API_KEY` 已设置 | 否则 Agent 降级 stub |
| `api_base` = `http://10.71.121.18:8000` | 不对则见下方修复 |
| Kiosk 本机 + LAN 均 `200` | 静态页可达 |
| 8000/8080 Listen 含 **`0.0.0.0`** | 仅 127.0.0.1 则执行 **§5** |

**若 `api_base` 仍是 127.0.0.1（一次性修复）：**

```powershell
$specPath = "E:\project\GameForge-K12\config\kiosk_edu_spec.json"
(Get-Content $specPath -Raw) -replace '"api_base"\s*:\s*"http://127\.0\.0\.1:8000"',
  '"api_base": "http://10.71.121.18:8000"' |
  Set-Content $specPath -Encoding UTF8
# Kiosk 为静态页，改完即可；API 无需重启。浏览器强刷 Ctrl+F5。
```

**若 health 失败或端口未 Listen → 继续 §5。**

**方式 B · PowerShell（与 exe 等价）**

```powershell
$Root = "E:\project\GameForge-K12"
$listen = @(Get-NetTCPConnection -LocalPort 8000,8080 -State Listen -ErrorAction SilentlyContinue)

if ($listen.LocalPort -contains 8000) {
  Write-Host "[跳过] API :8000 已在监听"
} else {
  Write-Host "[启动] API :8000 → 0.0.0.0"
  Start-Process -FilePath "$Root\backend\.venv\Scripts\uvicorn.exe" `
    -ArgumentList @("app.main:app", "--host", "0.0.0.0", "--port", "8000") `
    -WorkingDirectory "$Root\backend" `
    -WindowStyle Minimized
}

if ($listen.LocalPort -contains 8080) {
  Write-Host "[跳过] Kiosk :8080 已在监听"
} else {
  Write-Host "[启动] Kiosk :8080 → 0.0.0.0（工作目录=仓库根）"
  Start-Process -FilePath "$Root\backend\.venv\Scripts\python.exe" `
    -ArgumentList @("-m", "http.server", "8080", "--bind", "0.0.0.0") `
    -WorkingDirectory $Root `
    -WindowStyle Minimized
}

Start-Sleep -Seconds 3
Get-NetTCPConnection -LocalPort 8000,8080 -State Listen |
  Select-Object LocalAddress, LocalPort, State
Invoke-RestMethod http://127.0.0.1:8000/health | Select-Object status, play_launch_mode
```

| 期望 | 说明 |
|------|------|
| 8000、8080 均 Listen 且含 `0.0.0.0` | 学生机可连 |
| `/health` → `status=ok`（或 degraded 但 store_ok 可接受） | Redis 未起时可能 degraded |

### §8 · 映射 Z: + Godot + 启动脚本 + 连通自检

```powershell
$ServerIp  = "10.71.121.18"
$ShareUnc  = "\\$ServerIp\GameForgeWorkspace"
$Godot     = "C:\Godot\Godot_v4.6.3-stable_win64.exe"
$GodotShare = "Z:\_tools\Godot\Godot_v4.6.3-stable_win64.exe"

# --- 8.1 映射 Z: ---

  Write-Error "共享盘无 Godot：请先在服务器执行 §2.5。期望: $GodotShare"

  Copy-Item $GodotShare $Godot -Force
  Write-Host "已从 Z: 安装 Godot 到 $Godot"
}

# 备选（仅学生机可访问 GitHub 时）：
# $zip = "$env:TEMP\Godot_v4.6.3-stable_win64.exe.zip"

# Expand-Archive $zip "C:\Godot" -Force

# --- 8.3 启动脚本（只需部署一次）---
New-Item -ItemType Directory -Force -Path "C:\GameForge" | Out-Null
@'

  [Parameter(Mandatory=$true)][string]$ProjectPath
)

$Drive  = "Z:"
if ($ProjectPath.StartsWith($Prefix)) {
  $rel = $ProjectPath.Substring($Prefix.Length).TrimStart('\')
  $local = Join-Path $Drive $rel
} else {
  $local = $ProjectPath
}
if (-not (Test-Path (Join-Path $local "project.godot"))) {
  Write-Error "找不到 project.godot: $local"
  exit 1
}
Start-Process -FilePath $Godot -ArgumentList @("--path", $local)
Write-Host "已启动 Godot: $local"
'@ | Set-Content -Path "C:\GameForge\launch-session-godot.ps1" -Encoding UTF8
Test-Path "C:\GameForge\launch-session-godot.ps1"

# --- 8.4 连通性自检（30 秒）---
$rows = @()
$rows += [pscustomobject]@{ Check = "Z: 映射"; Pass = (Test-Path "Z:\") }
$rows += [pscustomobject]@{ Check = "Godot exe"; Pass = (Test-Path $Godot) }
$rows += [pscustomobject]@{ Check = "启动脚本"; Pass = (Test-Path "C:\GameForge\launch-session-godot.ps1") }
```
