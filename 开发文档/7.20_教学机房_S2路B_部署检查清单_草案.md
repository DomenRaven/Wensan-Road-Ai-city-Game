# 7.20 · 教学机房 S2-路B 部署检查清单（草案）

> **状态**：草案 · 不替代机房 IT 实装验收  
> **对应**：需求 v1.4 §8.3 · 施工规范 W7 · `PLAY_LAUNCH_MODE=local_share`  
> **展厅**：保持 `PLAY_LAUNCH_MODE=server`（默认），勿对本文件机房项照搬。

---

## 1. 架构一句话

中央服务器跑 API / Kiosk / 会话 / workspace 权威目录；学生机经 **共享盘映射** 看到本人会话目录，用 **本机 Godot 4.6** 打开试玩。服务器 **不为** 全班起 Godot 窗。

---

## 2. 服务器侧

| # | 项 | 建议 |
|---|----|------|
| 1 | `PLAY_LAUNCH_MODE` | `local_share` |
| 2 | `MAX_SESSIONS` | ≥70 |
| 3 | `MAX_CONCURRENT_AGENTS` | 4～8；`AGENT_QUEUE_WAIT_SEC` 按机房调 |
| 4 | `workspace` 目录 | 放在 NAS/共享卷；对映射账号只读他人、可写本人会话 |
| 5 | `/health` | 确认 `play_launch_mode=local_share` |
| 6 | 点试玩 | API 返回 `ready_for_local_godot=true` + `project_path`，**无**服务器 PID |

---

## 3. 学生机侧

| # | 项 | 建议 |
|---|----|------|
| 1 | Godot | 预装 **4.6 Standard**（与展厅一致） |
| 2 | 映射盘 | 固定盘符指向服务器 `workspace`（或等价挂载） |
| 3 | 路径对齐 | 浏览器展示的 `project_path` 与本机可见路径一致（或脚本做盘符替换） |
| 4 | 启动 | 极简脚本：`Godot.exe --path <本人会话目录>`；或手工「导入/打开」`project.godot` |
| 5 | 释放会话 | **先关本机 Godot**，再结束/release 会话（避免删占用中的目录） |

---

## 4. 抽样验收（非 C70-Play 全量）

1. 登录/游客各开一局，完成制作后点试玩 → 页面显示本机路径，服务器无新 Godot 进程。  
2. 本机用 Godot 打开该路径可玩。  
3. 另一账号不可打开他人会话目录（ACL）。  
4. 展厅机回切 `PLAY_LAUNCH_MODE=server` 后，仍可服务器起窗（回归）。
