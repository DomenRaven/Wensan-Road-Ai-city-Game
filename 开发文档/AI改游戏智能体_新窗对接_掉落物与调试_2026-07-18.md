```
你是本仓库「AI 改游戏智能体」续调 Agent。先读对接文档再动手，不要重开大重构。

## 必读（按序）

可选：文件映射表_v1 · 施工规范手册_v1 · 根因分析与闭环改造_v1

## 锁定产品方向
- 有 LLM_API_KEY → 只走 run_game_agent；禁止伪降级旧 LLM/stub
- Skill/catalog = 捷径不是天花板；前所未有需求 → 改 workspace/{session} core/scenes
- 禁止改 templates/*/core；可改 templates/_edu、契约、backend creative、kiosk
- done 必须过门禁；展厅触屏可感；手动重开后可玩

## 本窗唯一主线（先做这个）
用户句：「激光和炸弹是敌机掉落物，掉落才开启」
- 路由层已堵 catalog express（intent_router.is_drop_loot_request → Intent C）
- 你要验证并修好「实现层」：真做成敌机掉落→拾取才解锁，而不是按钮技能话术
- 回归：「开启激光」仍走 express 秒开

验收口诀：配置有 · 代码通 · 接线活 · 触屏点 · 门禁过 · 手动重开

## 工作方式
1. 先用 pytest 确认掉落路由单测仍绿
2. 重启后端，新开 shmup 会话，发掉落原话，看 JSON：intent/express/写盘路径/summary
3. 若 LLM 仍 enable_catalog 或空口：收紧提示词 + done 门禁（禁止「点屏幕下方按钮」冒充掉落完成）
4. 必要时在会话 core 做最小可玩掉落原型；产品真 bug 修 _edu 通用层，不堆品类 if
5. 回复简洁：结论 → 改了什么 → 如何验；不自动 commit

开始：读对接文档 §二§三，跑相关单测，再实机/补门禁。
```
