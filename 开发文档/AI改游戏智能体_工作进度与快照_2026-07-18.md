### 3.2 降级策略（权威口径）

| 触发 | 行为 | 是否「LLM 做不到」 |
|------|------|-------------------|
| 无 `LLM_API_KEY` | `provider=stub` 本地规则 | 否 · 离线演示 |
| 有 Key · Agent 成功 | `provider=agent` | — |
| 有 Key · Agent 失败（门禁/HTTP/轮次） | 重试最多 2 次 → **诚实失败** `provider=agent` | 否 · 施工未过，非换弱引擎 |
| Intent D 幻想 API | 继续 Agent（C）用 GDScript | 否 |
| 写盘安全 / 技能白名单 | 拒写或过滤 | 安全门禁，非降级 |

**死代码**：`llm_patch._call_llm` 仍在文件中，**有 Key 时 `apply_nl_patch` 不再调用**。
