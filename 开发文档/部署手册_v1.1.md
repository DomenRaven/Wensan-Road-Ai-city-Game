## 一、架构概览

```text
浏览器 (Chrome/Edge 全屏)
  ├─ Kiosk 静态页  :8080  →  /kiosk/  ·  /kiosk/edu/
  └─ FastAPI 后端  :8000  →  会话 · 生成 · play/launch · actions 轮询
         │
         └─ 外置 Godot 4.6 窗口（Win32 自动贴右半/下半屏）
```

| 组件 | 是否必须 | 说明 |
|------|----------|------|
| Python 3.11+ | ✅ | 后端 + 静态 HTTP 服务 |
| Godot 4.6 Standard | ✅ | B6/B7 试玩 launch |
| Redis 5.x | 推荐 | 会话持久；不可用时可内存降级 |
| Nginx | 可选 | 局域网单端口反代（`kiosk_lan_nginx.ps1`） |
| Node.js | ❌ | Kiosk 为纯静态 JS，运行时不需要 |
| Playwright | ❌ | 仅开发/E2E 验收用 |

### 3.1 Python（全新 Windows 必做）

1. 打开 [python.org/downloads](https://www.python.org/downloads/) 下载 **Windows installer (64-bit)**。
2. 安装时勾选 **Add python.exe to PATH**（否则 PowerShell 找不到 `python`）。
3. 安装完成后**新开** PowerShell 验证：

```powershell
python --version          # 应 ≥ 3.11
python -m pip --version
```

若提示找不到命令，可改用 `py -3 --version`，或将 Python 安装目录加入系统 PATH。

### 3.2 Godot 4.6 Standard（试玩必装）

1. 打开 [godotengine.org/download/windows](https://godotengine.org/download/windows/)。
2. 下载 **Standard** 版（**不要**选 .NET 版）：`Godot_v4.6.x-stable_win64.exe.zip`。
3. 解压到固定目录，例如 `C:\Godot\Godot461\`，得到 `Godot_v4.6.3-stable_win64.exe`。
4. 验证（路径替换为本机实际路径）：

```powershell
& "C:\Godot\Godot461\Godot_v4.6.3-stable_win64.exe" --version
& "C:\Godot\Godot461\Godot_v4.6.3-stable_win64.exe" --path "E:\文三路AI馆\2.ai生成游戏\templates\platformer"
```

能弹出 Godot 窗口即安装成功；记下 exe 完整路径，下一步写入 `backend\.env`。

### 3.3 PowerShell 脚本策略（首次运行 .ps1 前）

全新 Windows 可能禁止运行脚本，在 PowerShell 执行一次：

```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```

## 五、零基础上完整部署（推荐顺序）

在**全新、无历史配置**的 Windows 展厅 PC 上，按下列顺序操作一次即可跑通 B 链全链路。

| 步骤 | 操作 | 通过标准 |
|------|------|----------|
| 1 | 安装 Python 3.11+（§3.1）· Godot 4.6 Standard（§3.2）· Git | `python --version` · Godot 能打开 platformer 模板 |
| 2 | 克隆代码并 `git checkout v1.1`（§四） | 存在 `$ROOT\backend` · `$ROOT\kiosk` |
| 3 | 设置 PowerShell 脚本策略（§3.3） | `.\05-工具脚本\run_backend.ps1` 不被策略拦截 |
| 4 | **配置环境变量**（§七） | 存在 `$ROOT\backend\.env` 且 `GODOT_PATH` 为本机路径 |
| 5 | **安装 Redis**（§八，推荐） | `$ROOT\tools\redis\server\redis-server.exe` 存在 |
| 6 | **首次启动后端**（§六 或 §九 一键） | `curl http://127.0.0.1:8000/health` 返回 JSON |
| 7 | **启动 Kiosk 静态服务**（一键 exe 可跳过） | `http://127.0.0.1:8080/kiosk/` 可打开 |

## 七、环境变量（试玩前必配）

**在首次启动 API 或试玩之前**完成；否则 `play/launch` 将因默认 `GODOT_PATH`（开发机路径）失败。

复制模板并编辑：

```powershell
cd $ROOT
copy backend\.env.example backend\.env
notepad backend\.env
```

| 变量 | 必须 | 说明 | 示例 |
|------|------|------|------|
| `GODOT_PATH` | ✅ | Godot **GUI** 可执行文件路径（非 console 版优先） | `F:\Godot\...\Godot_v4.6.3-stable_win64.exe` |
| `REDIS_URL` | 推荐 | Redis 连接串 | `redis://127.0.0.1:6379/0` |
| `ALLOW_MEMORY_FALLBACK` | 可选 | Redis 不可用时用内存会话 | `true` |
| `DEPLOYMENT_SERVER_OS` | 可选 | 部署标注 | `Windows` |
| `DEPLOYMENT_TERMINAL_LAYOUT` | 可选 | 横/竖屏布局标注 | `landscape` |

**注意**

- **`GODOT_PATH` 为试玩硬依赖**；未配置时 health 仍可能 200，但 B6/B7 launch 返回 503。
- 修改 `config/creative_templates` 或 `code_anchors` 后须 **重启 API**。
- `GODOT_PATH` 可指向目录；launcher 会自动解析 `Godot_v4.6.3-stable_win64.exe`。
- **勿将** 含真实 API Key 的 `.env` 提交 Git。

## 十、局域网部署（可选）

同一 Wi‑Fi 下 pad/副屏访问本机 Kiosk。**前置**：本机已按 §五 完成部署，且 **API 已在 :8000 运行**。

```powershell
cd $ROOT
# 需本机已安装 nginx 且在 PATH 中
.\05-工具脚本\run_backend.ps1          # 终端 1：若未启动
.\05-工具脚本\kiosk_lan_nginx.ps1 -Port 9080 -BackendPort 8000
```

访问：`http://<本机局域网 IP>:9080/kiosk/edu/`

**须同步修改 API 地址**（否则 pad 上浏览器仍请求 `127.0.0.1:8000`）：

编辑 [`config/kiosk_edu_spec.json`](../config/kiosk_edu_spec.json)：

```json
"api_base": "http://192.168.x.x:9080/api"
```

其中 `192.168.x.x` 为本机局域网 IP；`:9080/api` 对应 nginx 反代到 backend（见 `kiosk_lan_nginx.ps1`）。

| 模式 | `api_base` 示例 |
|------|-----------------|
| 单机展厅（默认） | `http://127.0.0.1:8000` |
| nginx LAN 反代 | `http://<本机IP>:9080/api` |

> **限制**：A 链 `kiosk/wizard.js` 内 API 地址仍为硬编码 `127.0.0.1:8000`；局域网 pad 请优先使用 **B 链** `/kiosk/edu/` 并配置 `api_base`。

## 十六、展馆专用服务器 · 证书扫码下载

> **契约文件**：`config/exhibition_server.example.json`  
> **一键同步**：`05-工具脚本/apply_exhibition_config.ps1`  
> **Nginx 模板**：`05-工具脚本/nginx_exhibition.conf.example`

### 16.1 接口预留（已实现 · 实装时直接启用）

| 方法 | 路径 | 用途 |
|------|------|------|
| `PUT` | `/sessions/{session_id}/certificate` | Kiosk 上传 PNG · 返回 `download_url` + `download_token` |
| `GET` | `/public/certificates/{token}` | **游客扫码下载**（短期 token · 不暴露 session_id） |
| `GET` | `/sessions/{session_id}/certificate/download` | 馆内调试 / 同源直连（可选） |
| `GET` | `/bootstrap` | 返回 `certificate.public_download_base` 等部署字段 |
| `GET` | `/health` | 含 `certificate` 部署状态块 |

### 16.2 实装三步

```powershell
cd $ROOT
Copy-Item config\exhibition_server.example.json config\exhibition_server.json
# 编辑 exhibition_server.json · api.public_base 填游客可访问的 HTTPS 域名
.\05-工具脚本\apply_exhibition_config.ps1
# 配置 nginx（见 nginx_exhibition.conf.example）后重启 backend
.\05-工具脚本\run_backend.ps1
```

`backend/.env` 关键项：

```env
PUBLIC_API_BASE=https://你的展馆域名
CERTIFICATE_DOWNLOAD_TTL_SEC=259200
```

`config/kiosk_edu_spec.json` 同步项：`certificate.public_download_base`（与上同源）。

### 16.3 游客扫码流程

```text
触屏点「保存证书」→ 生成 PNG → PUT 上传 → 展示二维码
  → 二维码编码 https://域名/public/certificates/{token}
  → 游客手机（馆内 Wi-Fi 或 4G，只要能访问该域名）扫码下载
```

token 默认 **72 小时**有效；会话 `release` 时自动清理。

### 16.4 馆内 LAN 草案（开发/预演）

无公网域名时，可用展馆服务器局域网 IP：

```json
"public_base": "http://192.168.1.100:8000"
```

游客须连**同一网络**（馆内 Wi-Fi）。正式对公网参观建议 HTTPS 域名。

## 十七、常见故障

| 现象 | 排查 |
|------|------|
| `python` 不是内部或外部命令 | 重装 Python 并勾选 **Add to PATH** · 或新开终端 · 试 `py -3` |
| 无法运行 `.ps1` · 禁止脚本 | `Set-ExecutionPolicy RemoteSigned -Scope CurrentUser`（§3.3） |
| 首次 venv/pip 很慢或超时 | 使用 §六 清华镜像 · 检查网络/代理 |
| `Address already in use` :8000/:8080 | `netstat -ano \| findstr :8000` 查占用进程并结束 |
| launch 503 · GODOT_PATH | 确认已 `copy .env.example .env` 并填写本机 Godot 路径 · `templates/{genre}/project.godot` 存在 |
| Godot 启动即退出 | 用 **Standard GUI** 版 exe · 命令行 `Godot --path templates/platformer` 试开 |
| `window_placed=false` | 非 Windows · HWND 未找到 · 仍可从状态卡手动找窗 |
| Kiosk 白屏 / 配置加载失败 | 确认 `http.server` 在 **$ROOT** 启动，而非 `kiosk/` 子目录 |
| 配方/锚点改了不生效 | 重启 `run_backend.ps1` |
| 浏览器 API 连不上 | `kiosk_edu_spec.json` 的 `api_base` 与可达 API 地址一致（§十） |
| 证书扫码打不开 | `PUBLIC_API_BASE` / `public_download_base` 须为手机可访问地址 · nginx 须反代 `/public/certificates/` |
| 证书保存失败 | 确认 backend 已重启 · `vendor/html2canvas.min.js` 已加载 · 查看浏览器控制台 |
| Redis 连接失败 | 运行 `install_redis.ps1` + `run_redis.ps1` · 或保持 `ALLOW_MEMORY_FALLBACK=true` |
| `session_backend` 为 `memory` | 未启 Redis；展厅可接受，但重启 API 丢会话 |
| WinError 32 写 workspace | 关闭占用中的 Godot · 重启 API |
| 一键 exe 找不到项目根 | exe 必须在 `$ROOT`；用 `build_launcher.ps1` 重新生成 |
