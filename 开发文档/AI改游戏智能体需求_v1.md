## 0. 一句话

孩子在 **B6/B7 短对话**里提需求；智能体按 **品类无关的通用落地工作流**（意图路由 → 契约选路径 → 改会话副本 → **三层接线可玩** → 门禁 → 手动重开）实现可体验改动。禁止「只写文件口头 done」。LLM 不可用时 stub 降级并诚实标明。

**当前工作方向锁定**：优先完善「AI 修改（重制）游戏智能体」；模板引擎扩品类、展陈窗彩排等 **非本主线任务暂停**，除非阻塞智能体验收。

1. B1–B5 → 复制模板到 `workspace/{session}/`，**edu 注入**桥 / 触控 / chrome。

## 4. 通用落地工作流（v1.2 核心）

> 目标：**换品类、换需求仍走同一条管道**；飞机炸弹只是 recipe 实例，不是特例工程。

### 4.0 总览

```text
用户话 → 理解需求 → 意图路由(A/B/C/D)
      → 契约选路径 → 改会话副本
      → 三层落地(配置/代码/运行时接线) → 触屏可操作
      → done 门禁 → UI 展示 → 手动重开 → 可感知试玩
```

### 4.1 自主识别（v1.3 · LLM 主导）

> **不再**用硬路由「先分场景再只走一条流水线」当主控。路由 A/B/C/D 降为**建议**；智能体必须：诊断磁盘 → 读文件 → 选 Skill/契约 API → 施工 → **self_check** → done。

| 能力 | 要求 |
|------|------|
| 识别需求 | LLM 结合反馈与【会话诊断】判断开技能 / 修触屏 / 改数值 / 新机制 |
| 读盘 | `list_dir` / `read_file` / 启动时注入 `diagnose_workspace` |
| 选技能 | 契约 catalog + Learned Skills + bridge_apis |
| 自检 | `self_check` / `validate_gdscript`；done 仍过硬门禁 |
| 禁止 | 口头成功、幻想 API、反馈局复读 enable 冒充修复 |

历史 A/B/C/D 表仍作提示词参考：

| 类型 | 含义 | 首选动作 |
|------|------|----------|
| **A. 开预制** | catalog 内技能 | `enable_catalog_skill` + 运行时接线 |
| **B. 改已有** | 数值/外观/生成链/反馈修复 | tuning / 会话 core / 刷桥 / 守卫 |
| **C. 新机制** | 目录没有的玩法 | 沙箱 `apply(bridge)` |
| **D. 超能力面** | 需要尚不存在的钩子 | 诚实停，先扩 `_edu` |

偏离时以**门禁 + 自检**纠偏，而非死绑单一 recipe。

### 4.2 三层落地（写文件 ≠ 可玩）

| 层 | 内容 | 缺了会怎样 |
|----|------|------------|
| **L1 配置** | `enabled_skills` / tuning / theme | 有配置无玩法 |
| **L2 代码** | 会话 `core/*.gd` 或 `ai_sandbox/*.gd` | 有脚本未挂链 |
| **L3 运行时接线** | 桥 Autoload / 触控 overlay / 输入→效果 | **可玩的最后一公里** |

**硬规则**：仅完成 L1 不得 `done` 声称「已启用可玩技能」。catalog 技能必须在契约中声明 `runtime`（输入 / 效果 / 触屏），done 检查声明对应实现存在。

### 4.3 注入时机

| 时机 | 动作 |
|------|------|
| 会话生成（B5） | `edu_workspace` 注入 AiSandboxBridge、品类 hooks、**触控 overlay**、window chrome |
| AI 改游戏 | 只改 `workspace/{session}/`；templates 只读 |
| 沙箱加载 | 桥扫描 `core/ai_sandbox/*.gd`，调用 `apply(bridge)` |
| 试玩启动 | 全屏 + Always on Top；读最新会话文件 |

### 4.4 Capability Contract

路径：`config/agent_contracts/{genre}.json`

必含：

- `bridge_apis[]`  
- `catalog_skills[]`（建议含 `runtime: {input, effect, touch}`）  
- `edit_recipes[]`（意图 → action / paths / hint）  
- `hooks`  
- `notes`  
- `forbidden_invented_apis[]`  

### 4.5 写范围

| 允许 | 禁止 |
|------|------|
| 会话 `core/**`、`config/**`、`scenes/**`、`assets/**` | `templates/**` 玩法源、`project.godot`、危险 API |
| `templates/_edu/**`（桥/触控，经 edu 注入） | 发明 `add_method` 等幻想 API |

### 4.6 工具集

**基础**：`list_dir` / `read_file` / `write_file` / `enable_catalog_skill` / `search_learned_skills` / `done`  

**门禁**：`validate_gdscript` · `assert_apis_in_contract` · `assert_claims` ·（进度）`emit_progress`  

**建议**：`dry_run_godot`；确定性意图路由器；桥级 `ensure_touch_action(action_id, label)`  

### 4.7 `done` 门禁

1. 至少一次有效写入或 catalog 变更  
2. 新 `.gd` 语法/安全通过；无幻想 API  
3. 声称 ⊆ 磁盘（含「启用了 X」→ `enabled_skills` 含 X）  
4. how_to_play：重开提示 + **触屏操作说明**  
5. （目标）recipe `runtime` 检查点通过  

失败 → 禁止成功返回；再改（可数分钟）。

### 4.8 扩桥原则

宁扩 `templates/_edu/ai_sandbox_bridge.gd` 真方法，勿让模型伪造挂钩。  
触屏：优先通用 `ensure_touch_action`，避免每品类各写一套特例（shmup overlay 为过渡实现）。

### 4.9 LLM / 降级

| 状态 | provider | UI |
|------|----------|-----|
| 门禁全过 | `agent` | 智能体已改本局副本 |
| 失败/无 Key | `stub` / `llm` | 本地降级 · 可重试 |

## 7. 成功标准

1. 七品类：开预制 / 现场写 / 「没生效」再改；**重开后可感知**  
2. templates 玩法源 hash 不变（`_edu` 可改）  
3. 虚假声称不能 `provider=agent`  
4. 幻想 API 不能过门禁  
5. harvest 后坏片段不污染 Top-K  
6. 降级诚实；进度可辨；全屏置顶  
7. **换品类换需求仍走 §4 同一管道**（非单品类补丁堆叠）  
8. 新操作均有触屏入口
