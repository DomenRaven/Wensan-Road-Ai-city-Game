## 2. 设计口径

### UH-1 / UH-3 · 滚动与字号

- Grid/Flex 子项补 `min-height: 0` + 滚动容器 `overflow: auto`，避免内容撑破导致无滚动视口。
- 强制较宽滚动条（含 `-webkit-scrollbar`），触控 `overscroll-behavior: contain`。
- 代码区字号目标约 **1.05rem～1.1rem**，行高 ≥ 1.5。

### UH-2 · 「改后全文」= 全屏工作区 + Diff 高亮

- 「对照 Diff」：保留现有小窗 unified diff。
- 「改后全文」：**不再**在小窗内嵌全文；改为 `EduCodeBrowser.show({ turnId })`。
- 全屏内：完整文件树 + 读真实 workspace；打开某文件时若属本轮 Diff，按 unified diff 标注 add/del 行；未改文件正常着色。
- 入口文案可副标「本轮改动高亮」。

### UH-4 · 评价持久

- 提交仍走现网 `POST …/rating`（可改评 revision）。
- 新增 `GET …/turns/{turn_id}/rating`：无评价 → 404 或 `{exists:false}`。
- 弹层 `renderResult` / `bindRatingUI`：先拉已有评价并回填；跳过/关闭不清除服务端记录。
- 新一轮 `nl-patch` 成功（新 `turn_id`）后展示空评价表。

### UH-5 · 注释

- 仅加强 LLM 工作法文案；**不**为单场景堆 Intent 补丁；不改冻结 `core` 源模板。

## 3. 自测清单

1. 制作完成 → 查看游戏代码：左右均可滚到底；字号明显大于热修前。  
2. AI 改游戏一轮 → 查看本轮改动 → 对照 Diff 仍小窗可用 → 点「改后全文」进全屏，绿/红高亮，可切文件。  
3. 提交 3 星 + 一句评语 → 关闭弹层 → 再打开：仍见 3 星与评语。  
4. 再发一轮对话拿到新回复：评价区为空，可重新打星。  
5. 抽查本轮新增 `.gd`：关键分支/计数有中文 `#` 注释（Live，视模型）。
