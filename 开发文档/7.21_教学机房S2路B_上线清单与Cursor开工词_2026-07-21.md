## 2. T1 · 防火墙放行（8000 / 8080）

### 2.1 手动操作（须管理员 PowerShell）

**右键「开始」→ Windows PowerShell（管理员）** 或「终端（管理员）」：

```powershell
# 查看是否已有规则
Get-NetFirewallRule -DisplayName "GameForge*" | Format-Table DisplayName, Enabled, Direction

# 新建入站允许（机房 LAN）
New-NetFirewallRule -DisplayName "GameForge API 8000" `
  -Direction Inbound -Protocol TCP -LocalPort 8000 -Action Allow -Profile Any

New-NetFirewallRule -DisplayName "GameForge Kiosk 8080" `
  -Direction Inbound -Protocol TCP -LocalPort 8080 -Action Allow -Profile Any

# 验证规则
Get-NetFirewallRule -DisplayName "GameForge*" | Get-NetFirewallPortFilter | Format-Table

# 验证端口在监听（服务须已启动）
Get-NetTCPConnection -LocalPort 8000,8080 -State Listen | Select-Object LocalAddress, LocalPort, OwningProcess
```

期望：`LocalAddress` 含 `0.0.0.0` 或 `*`。

**若无管理员权限**：把上面命令交给机房管理员，或远程时请管理员执行。

**GUI 方式**：控制面板 → Windows Defender 防火墙 → 高级设置 → 入站规则 → 新建规则 → 端口 → TCP **8000**、**8080** → 允许连接。

## 3. T2 · workspace 共享（S2-路B 核心）

### 3.1 目录结构（登录用户）

```text
E:\project\GameForge-K12\workspace\
  users\
    {user_id}\
      {session_id}\
        project.godot
        core\  scenes\  config\
```

试玩页 `project_path` 示例：

```text
E:\project\GameForge-K12\workspace\users\{user_id}\{session_id}
```

### 3.2 推荐共享方案（Windows 文件共享）

| 项 | 建议值 |
|----|--------|
| 共享名 | `GameForgeWorkspace` |
| 共享路径 | `E:\project\GameForge-K12\workspace` |
| UNC | `\\10.71.121.18\GameForgeWorkspace` |
| 学生映射盘符 | `Z:` → 上述 UNC |

**路径换算（学生机脚本用）：**

```text
E:\project\GameForge-K12\workspace\users\...  →  Z:\users\...
```

### 3.3 手动操作（GUI · 管理员）

1. 资源管理器打开 `E:\project\GameForge-K12\workspace`  
2. 右键 → **属性** → **共享** → **高级共享**  
3. 勾选「共享此文件夹」· 共享名 **`GameForgeWorkspace`**  
4. **权限**：  
   - `Everyone` 或学生域组：**更改**（可写本人目录；见 NTFS）  
   - 服务运行账户 / Administrators：**完全控制**  
5. **安全**（NTFS）→ 高级：  
   - 禁用继承按需调整  
   - `users\{每个 student 的 user_id}\`：**该用户完全控制**，其他学生 **无列表/读取**（需 IT 按账号批量或按组策略）  
   - **简化首课**：若来不及逐用户 ACL，至少保证共享仅内网可访问；**正式课仍须 IT 补 ACL**  
6. 防火墙：**文件和打印机共享** 入站（SMB 445）若学生机映射盘失败再开  

PowerShell 快速共享（管理员，**简化版 · 首课应急**）：

```powershell
$path = "E:\project\GameForge-K12\workspace"
New-SmbShare -Name "GameForgeWorkspace" -Path $path -FullAccess "Administrators" -ChangeAccess "Users"
# 若学生不在 Users 组，改为实际域组名，或临时 -ChangeAccess "Everyone"（仅内网短期，不推荐长期）
Get-SmbShare GameForgeWorkspace
```

### 3.4 `.env` 是否改 WORKSPACE_DIR

**首课可不改**：继续用 `E:\project\GameForge-K12\workspace`（默认），学生通过 **Z:\** 映射访问同一物理目录。

仅当 workspace 要迁到别的盘/UNC 根时才设：

```env
WORKSPACE_DIR=E:\project\GameForge-K12\workspace
```

改后**重启 API**。

## 5. T4 · 学生机批量准备（IT / 教师）

### 5.1 安装 Godot 4.6 Standard

- 统一路径，例如：`C:\Godot\Godot_v4.6.3-stable_win64.exe`  
- 验证：`& "C:\Godot\Godot_v4.6.3-stable_win64.exe" --version`

### 5.2 映射网络驱动器（每台学生机）

**图形界面**：资源管理器 → 此电脑 → 映射网络驱动器 → `Z:` → `\\10.71.121.18\GameForgeWorkspace` → 登录凭据（若需）

**命令行（可 GPO/开机脚本）：**

```powershell
net use Z: \\10.71.121.18\GameForgeWorkspace /persistent:yes
```

验证：打开 `Z:\users\` 能看到目录（权限正确时只能看自己的）。

### 5.3 启动脚本（每台学生机桌面）

保存为 `C:\GameForge\launch-session-godot.ps1`：

```powershell
param(
  [Parameter(Mandatory=$true)][string]$ProjectPath
)
$Godot = "C:\Godot\Godot_v4.6.3-stable_win64.exe"
$Prefix = "E:\project\GameForge-K12\workspace"
$Drive  = "Z:"
if ($ProjectPath.StartsWith($Prefix)) {
  $rel = $ProjectPath.Substring($Prefix.Length).TrimStart('\')
  $local = Join-Path $Drive $rel
} else {
  $local = $ProjectPath
}
if (-not (Test-Path (Join-Path $local "project.godot"))) {
  Write-Error "找不到 project.godot: $local"
  exit 1
}
Start-Process -FilePath $Godot -ArgumentList @("--path", $local)
Write-Host "已启动 Godot: $local"
```

**用法**：从试玩页复制 `project_path`，PowerShell 执行：

```powershell
powershell -ExecutionPolicy Bypass -File C:\GameForge\launch-session-godot.ps1 `
  -ProjectPath "E:\project\GameForge-K12\workspace\users\...\会话ID"
```

## 9. 故障速查

| 现象 | 处理 |
|------|------|
| 学生机网页打不开 | 防火墙 8000/8080；服务是否 0.0.0.0 |
| Godot 找不到路径 | Z: 映射失败；检查 SMB 445；路径换算 |
| AI 显示本地降级 | 补 LLM_API_KEY 并重启 API |

| 登录 500 | 勿删 learning.db |
