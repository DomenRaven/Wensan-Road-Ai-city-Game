## 1. 立项动机（纠偏后的 AG-1）

shmup Live：用户「每过 20 秒无敌 + 充能条 + 彩色弹…」。

| 轮次 | Diff 事实 | 口头 summary |
|------|-----------|--------------|
| T1 | 变量 / HUD / 效果分支检查 `_god_mode_active` | 声称已做 20s 循环 |
| T2「没生效」 | 仅 `_ready` 初始化 | 声称已加 `_update_god_mode` 每帧更新（**盘上无**） |
| T3「没生效」 | 才写入 `_update_god_mode` 并接到 `_process` | 时间轴开始真正运转 |

结论：

1. **LLM 语义理解正确**（始终按时间轴表述；终盘无 kill 充能）。  
2. 失败模式是 **半成品交付 + 自信 summary + 门禁过浅**（有写入即过）。  
3. 用户「像击败充能」多为 HUD「充能 %」+ 前两轮条不走的体验错觉，**不是**语义套错模板。  
4. 此前 tip「禁止击杀冒充时间」方向偏了；本规范以 **证据 / 接线** 为主修。

## 2. 产品原则（与总纲对齐）

延续 [`7.19 总体设计`](./7.19_AI改游戏智能体_总体设计需求_v1.0.md) **G11 提示软 · 门禁硬**：

| 交给 LLM（自由） | 不交给 LLM 单独裁定 |
|------------------|---------------------|
| 怎么理解原话、拆 goals、选实现 | 「我觉得已经生效」 |
| 读哪些文件、怎么最小 patch | 无证据的 done |
| 用自然语言写 summary / how_to_play | 自己出题自己批改过门禁 |
| 在 `evidence[]` 里**指出**符号与调用点 | 用散文替代可解析证据 |

机器层只做**廉价、可单测**的核对：证据字段齐全、符号存在、调用点命中、反馈轮有真 diff。

## 3. 目标架构

```
用户原话
  → LLM：understanding + goals + 读盘施工（全开，不收紧创作）
  → LLM：done 前填 evidence[]（结构化，模型负责找证据）
  → 机器：校验 evidence ⊆ 磁盘（符号 / 调用 / 路径）
  → 机器：既有 run_done_gates + dry_run_godot（保留）
  → 反馈「没生效」：系统对比「上轮 claimed vs 本轮 diff」逼真差分
```

### 3.1 `evidence[]` 草案（done / self_check 共用）

每条至少：

```json
{
  "goal": "每过20秒进入无敌",
  "path": "core/player_ship.gd",
  "symbol": "_update_god_mode",
  "wired_by": "_process",
  "note": "delta 冷却 20s → 无敌 5s"
}
```

规则：

- 每个 goal 至少 1 条 evidence（或诚实 `missing` + 继续施工，不得 done）。  
- `symbol` 须在 `path` 中可搜到定义（`func symbol` / `var symbol` / 等）。  
- 若机制依赖每帧/定时：`wired_by` 须为 `_process` | `_physics_process` | `Timer` | 明确 `connect(` 信号；机器在同文件或声明的调用方文件中核对引用。  
- summary **不得**声称 evidence 未列出的能力（与既有 assert_claims 协同；本规范优先补「接线」洞）。

### 3.2 反馈轮（没生效）

系统侧（非再堆散文 tip）：

1. 注入上轮 `sandbox_files` / `evidence`（若有）与「本局近期改动」。  
2. 本轮若 `gate_passed` 且 diff 相对上轮 **空或仅空白/注释**：回灌硬错误，要求先 read 再最小 patch。  
3. 禁止接受与上轮 summary 高相似且无新写入的「已修复」交差（启发式即可，单测锁住）。

### 3.3 提示词调整（施工窗执行）

- **削弱/改写**「时间 vs 击杀」窄 tip：改为「周期机制须在 evidence 声明 wired_by」。  
- `_AGENT_SYSTEM` / `self_check`：done 前必须带 `evidence`（或工具 `self_check` 产出同结构）。  
- **不加**品类专用 Intent if；通用符号/调用核对即可。
