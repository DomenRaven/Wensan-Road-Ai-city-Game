## 一、架构概览

```text
浏览器 (Chrome/Edge 全屏)
  ├─ Kiosk 静态页  :8080  →  /kiosk/  ·  /kiosk/edu/   ← B 链主入口
  └─ FastAPI 后端  :8000  →  会话 · 生成 · play/launch · 日榜 · 触控键盘 · 证书 token
         │
         ├─ 外置 Godot 4.6 窗口（Win32 自动贴右半/下半屏）
         └─ 七款触屏 overlay（platformer … racing · 无物理键盘可玩）
```

| 组件 | 是否必须 | 说明 |
|------|----------|------|
| Python 3.11+ | ✅ | 后端 + 静态 HTTP 服务 |
| Godot 4.6 Standard | ✅ | B6/B7 试玩 launch |
| Windows 触控屏 / 平板模式 | ✅ 展厅 | B1/B2 输入依赖系统 TabTip（`tabtip_native`） |
| Redis 5.x | 推荐 | 会话持久；不可用时可内存降级 |
| Nginx | 可选 | 局域网单端口反代 · 证书扫码公网域名 |
| Node.js | ❌ | Kiosk 为纯静态 JS |
| Playwright | ❌ | 仅开发/E2E 验收用 |

**v1.2 相对 v1.1 新增**

| 能力 | 说明 |
|------|------|
| P4-B 七款触屏 | `_edu/*_touch_overlay.gd` 注入 · shmup 触屏拖动 · fighting 虚拟键 |
| P4-C 展厅 UI | B1 泡泡 · B2 名字 · 揭幕烟花 · B4 卡片 · B5 剧场 · 证书 PNG · 日榜 |
| 日榜 | `leaderboard.js` · `GET /leaderboard/daily/{genre}` · 关窗弹榜 |
| 触控键盘 | `POST /kiosk/touch-keyboard/{show,hide,warm}` · Windows TabTip COM |
| Godot 内嵌 P4-A | **挂起** · 维持 v1.1 外置窗方案 |

## 二、硬件与系统

| 项 | 建议 |
|----|------|
| 操作系统 | **Windows 10/11 64 位**（Godot 归位 + TabTip 触控键盘） |
| 显示器 | 横屏 1920×1080 展厅大屏；竖屏 pad 1080×1920 可选 |
| 触控 | **电容触屏一体机**；系统设置中启用「平板模式」或「触摸键盘」 |
| 内存 | ≥ 8 GB（Godot + 浏览器 + API 同机） |
| 磁盘 | ≥ 2 GB 可用（含 `workspace/` 会话工作区） |
| 网络 | 本机环回即可；证书扫码 / 多终端需局域网或公网 |

**非 Windows**：Kiosk 与 API 可运行，但 **Godot 外置窗自动贴边** 与 **TabTip 触控键盘** 不可用。

### 3.1 Python（全新 Windows 必做）

1. 打开 [python.org/downloads](https://www.python.org/downloads/) 下载 **Windows installer (64-bit)**。
2. 安装时勾选 **Add python.exe to PATH**。
3. 新开 PowerShell 验证：

```powershell
python --version          # 应 ≥ 3.11
python -m pip --version
```

### 3.2 Godot 4.6 Standard（试玩必装）

1. 下载 **Standard** 版（**不要** .NET 版）。
2. 解压到固定目录，例如 `C:\Godot\Godot461\`。
3. 验证：

```powershell
& "C:\Godot\Godot461\Godot_v4.6.3-stable_win64.exe" --version
& "C:\Godot\Godot461\Godot_v4.6.3-stable_win64.exe" --path "E:\文三路AI馆\2.ai生成游戏\templates\platformer"
```

记下 exe 完整路径，写入 `backend\.env` 的 `GODOT_PATH`。

### 3.3 PowerShell 脚本策略

```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```

### 3.4 展厅触控键盘（v1.2 必知）

B1/B2 文本输入通过 **Windows 系统 TabTip** 唤起，非网页虚拟键盘。

- 触屏点击输入框 → 后端 `POST /kiosk/touch-keyboard/show`
- 点击输入区外或导航按钮 → `hide`
- 需 **Windows 10/11** · 建议开启系统「触摸键盘」服务
- 开发机无触屏时可用鼠标点击输入框验证 API（TabTip 可能不出现，属正常）

| 步骤 | 操作 | 通过标准 |
|------|------|----------|
| 1 | 安装 Python · Godot · Git（§三） | `python --version` · Godot 能打开 platformer |

## 七、环境变量（试玩前必配）

```powershell
cd $ROOT
copy backend\.env.example backend\.env
notepad backend\.env
```

| 变量 | 必须 | 说明 | 示例 |
|------|------|------|------|
| `GODOT_PATH` | ✅ | Godot GUI exe | `C:\Godot\...\Godot_v4.6.3-stable_win64.exe` |
| `REDIS_URL` | 推荐 | Redis 连接串 | `redis://127.0.0.1:6379/0` |
| `ALLOW_MEMORY_FALLBACK` | 可选 | Redis 不可用时内存会话 | `true` |
| `PUBLIC_API_BASE` | 扫码实装 | 证书二维码公网 HTTPS 根 | `https://gameforge.example.com` |
| `CERTIFICATE_DOWNLOAD_TTL_SEC` | 可选 | token 有效期秒 | `259200` |

**注意**

- 未配 `GODOT_PATH` 时 health 仍可能 200，但 `play/launch` 返回 503。
- **C-08 证书扫码**：API 已就绪；须配 `PUBLIC_API_BASE` + nginx（§十六）后手机才可扫码下载。
- 勿将含真实 Key 的 `.env` 提交 Git。

## 九、展厅启动

### 9.1 一键启动（推荐 · 启动器 v1.2）

**首次打包**（需 Python 3.11+ 与 PyInstaller，仅做一次）：

```powershell
cd $ROOT
.\05-工具脚本\build_launcher.ps1
```

生成：

| 文件 | 说明 |
|------|------|
| `启动游戏工坊.exe`（仓库根目录） | 双击启动 · **须保留在 $ROOT** |
| `05-工具脚本\dist\启动游戏工坊.exe` | 构建输出副本 |

**v1.2 启动器行为**

1. 尝试启动 Redis（若已安装且未运行）
2. 若 `:8000` / `:8080` **已在运行则跳过**（可重复双击，不冲突）
3. 创建/复用 `backend/.venv` 并启动 API `:8000`
4. 启动 Kiosk 静态服 `:8080`（`--bind 127.0.0.1`）
5. 探测 `/kiosk/edu/` 就绪后打开浏览器

```powershell
.\启动游戏工坊.exe                  # 默认 B 链 edu
.\启动游戏工坊.exe --mode fast      # A 链快玩
.\启动游戏工坊.exe --no-browser     # 不自动开浏览器
```

关闭控制台窗口或按 **Enter** 停止**本启动器拉起的**后台进程（已存在的服务不会被终止）。

**前提**：本机 Python 在 PATH · `backend/.env` 已配 `GODOT_PATH` · exe 在 `$ROOT`。

### 9.2 手动启动（开发调试）

**终端 1 · 后端**


> `http.server` 工作目录必须是 **$ROOT**，不能是 `kiosk/`。

|------|-----|

## 十五、常见故障

| 现象 | 排查 |
|------|------|
| `python` 找不到 | 重装 Python 勾选 Add to PATH · 试 `py -3` |
| `:8000` / `:8080` 占用 | `netstat -ano \| findstr :8000` 结束进程 · 或直接用 v1.2 exe（会跳过已运行端口） |
| launch 503 | 检查 `backend/.env` 的 `GODOT_PATH` |
| Kiosk 白屏 | `http.server` 须在 **$ROOT** 启动 |
| 触控键盘不出现 | Windows 触屏/平板模式 · API `:8000` 可达 · 须从 `http://127.0.0.1:8080/kiosk/edu/` 进入 |
| 键盘不收起 | 刷新页面 · 确认 `touch-keyboard.js?v=7.4-c07-14` 加载 |
| 日榜不弹 | 须**关闭 Godot 窗** · pingpong 须整局 `session_end` |
| 证书保存失败 | `vendor/html2canvas.min.js` · backend 已重启 |
| 扫码打不开 | `PUBLIC_API_BASE` 须手机可访问 · nginx 反代 `/public/certificates/` |
| `session_backend: memory` | 未启 Redis；可接受，重启 API 丢会话 |
| exe 找不到项目根 | exe 必须在 `$ROOT` · 重新 `build_launcher.ps1` |
