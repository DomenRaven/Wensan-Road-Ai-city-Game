## 0. 总判（为何像「没实现」）

| 证据 | 结论 |
|------|------|
| 顶栏仍见「← 展厅快玩」 | 磁盘 `index.html` **已删除**该按钮；现场页仍像旧版 → **浏览器缓存旧 HTML/JS** 高度可疑 |
| 证书按钮仍为「保存证书」 | 新版应为扫码引导；旧 `certificate.js` 仍在跑 |
| 日志「降级模式 · 可试玩经典版」 | 新版已改文案；旧 `edu-wizard.js` 仍在跑 |
| 无「用 AI 改代码」按钮 | 新版 B6/B7 已注入；旧脚本无此 DOM |
| `POST generate/v2` → **404** | 会话在 B5 中途被 **release**，workspace 未生成 |
| `POST play/launch` → **404 Session not found** | 同上；故「开始试玩」失败、「无 workspace」 |

**根因链（试玩失败）**

1. A 链与 B 链共用 `sessionStorage` key：`gameforge_kiosk_session_id`  
2. 打开 `/kiosk/`（或点残留「展厅快玩」）→ A 链 `cleanupStaleSession` / 页面卸载 → **release 掉 B 链会话**  
3. B5 `generate/v2` 404 → `workspacePath` 空 → 讲解员加载 core 报「无 workspace」→ 开始试玩 404  

**仓库内任务书项**：多数已在代码落地；本次现场失败 = **缓存旧前端 + 会话被误杀**，再叠加缺失的「起名预制按钮」新需求。
