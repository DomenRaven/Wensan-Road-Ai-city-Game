## 3. P0 工作包拆分（建议顺序）

依赖：先有用户/会话归属与学情库，再 Diff/评价；F1 可与 F2 并行但证书门闩依赖 B6。

### W1 · 入口与账号（F4a）

| 项 | 做法要点 | 验收 |
|----|----------|------|
| 初始页 | Kiosk 新页：游客 / 登录（注册+登录） | 不直接进 B1 |
| 注册 | `username`+`password`+`nickname`；开放；密码哈希 | 无邀请码 |
| 会话绑定 | 登录用户 `user_id`↔`session_id`；单用户 1 活跃会话 | 越权 403 |
| 命名 | 登录跳过「你的名字是？」；`creator_name=nickname`；默认名 F4-N3（品类名来自 `genre_display_names`） | E2E-0b |
| 路径 | 登录：`workspace/users/{user_id}/{session_id}/`；游客保持 `workspace/{session_id}/` | 与 `workspace_root_for_session` 改造一致 |
| 游客 | 完整 B 链仍可用 | 展厅/游客不破 |

### W2 · 学情库骨架（F5）

| 项 | 做法要点 | 验收 |
|----|----------|------|
| 存储 | `data/learning_analytics/learning.db`（SQLite WAL）+ 可选 `blobs/` | 路径不进 learned_skills |
| 表 | User / PlaySession / AgentTurn / TurnRating /（Diff 元数据可后置） | schema 可迁移 |
| 回合落库 | nl-patch 结束写入 `user_text` + **`agent_reply_full`**（按需求 F5-L2：`message\|\|summary` + how_to_play） | release 后仍在 |
| 单测 | release 后查库；拼装规则单测 | 绿 |

### W3 · 星级评价（F3）

| 项 | 做法要点 | 验收 |
|----|----------|------|
| UI | nl-patch 结果区 1～5 星 + 五档文案；可选短评；可跳过 | 与需求量表一致 |
| API | `POST .../turns/{turn_id}/rating` | 可改评留痕 |
| 注入 | 下一轮 nl-patch 注入 `previous_turn_user_rating`（非伪造用户话） | 有单测/探针断言 |
| 落库 | TurnRating → SQLite | 长期可查 |

### W4 · Diff（F2）

| 项 | 做法要点 | 验收 |
|----|----------|------|
| 快照 | 每轮 Agent **开始前** before；结束后出 Diff | 多轮各自对照 |
| UI | 绿增改 / 红删+斜体；+/- 前缀；可看改后全文 | 对齐 Cursor 观感 |
| 注释 | 复用长回复 + 规则模板 | 不另调 LLM |
| 持久 | Diff 元数据/文本进学情或 blobs | release 后可回看该轮 Diff |

### W5 · 真代码浏览（F1）

| 项 | 做法要点 | 验收 |
|----|----------|------|
| 门闩 | B5 完成 + **证书保存成功** 后亮「查看游戏代码」 | 未保存置灰 |
| API | `workspace/tree`；`workspace/file` 白名单扩到 **`scenes/`**（保留 config/core） | 越权/穿越拒绝 |
| UI | 独立页：文件树 + 行号/高亮阅读区；文件级说明（可先占位表） | 内容=会话磁盘 |
| 只读 | 禁止在此页写盘 | — |

### W6 · S4 最小排队（F4b 部分）

| 项 | 做法要点 | 验收 |
|----|----------|------|
| 帽 | `max_concurrent_agents`（默认 4～8，可配） | 超额排队或明确繁忙 |
| 单用户 | 同时仅 1 个进行中的 nl-patch | — |
| UI | 至少中文「排队中/人数已满」 | 不静默挂死 |
| 会话数 | 部署文档/配置将 `max_sessions` 提到 ≥70（代码可配） | 配置项存在 |

### W7 · S2-路B 工程钩子（不替代机房 IT）

| 项 | 做法要点 | 验收 |
|----|----------|------|
| 配置 | 如 `play_launch_mode=server\|local_share`（名可微调） | 展厅默认 `server`（现网行为） |
| local_share | `play/launch` **不**在服务器起 Godot；返回本机会话路径/准备就绪信息，供机房脚本启动 | 单测/契约测 |
| 文档 | 在部署说明草案中写「映射盘 + 本机 Godot」检查清单 | 可另 PR |
